# triage-priority-matrix

## What is a Triage Priority Matrix?

A triage priority matrix is a systematic framework that categorizes issues based on two critical dimensions: **urgency** and **impact**. This matrix helps teams quickly assess and prioritize work items to allocate resources effectively and ensure critical problems are addressed promptly.

## Urgency vs Impact

**Urgency** refers to how quickly an issue needs attention, typically measured by time sensitivity and deadlines. **Impact** measures the severity of consequences when an issue occurs, including user experience, business revenue, system functionality, and stakeholder satisfaction.

The matrix combines these dimensions to create clear priority levels that guide decision-making processes.

## Priority Levels (P0-P4)

### P0 - Critical
- **Definition**: System outage or critical business disruption
- **Examples**: Complete service failure, data loss, security breach
- **Response Time**: 15-30 minutes
- **Resolution Time**: 2-4 hours

### P1 - High
- **Definition**: Major functionality degradation affecting many users
- **Examples**: Performance issues, major bugs impacting core features
- **Response Time**: 1-2 hours
- **Resolution Time**: 1-2 days

### P2 - Medium
- **Definition**: Moderate impact with acceptable workarounds
- **Examples**: Minor bugs, feature requests, documentation gaps
- **Response Time**: 4-8 hours
- **Resolution Time**: 1-2 weeks

### P3 - Low
- **Definition**: Minor issues with minimal impact
- **Examples**: Cosmetic issues, minor enhancements, questions
- **Response Time**: 1-2 days
- **Resolution Time**: 2-4 weeks

### P4 - Very Low
- **Definition**: Non-critical suggestions or future improvements
- **Examples**: Feature ideas, wishlist items, documentation improvements
- **Response Time**: 1-2 weeks
- **Resolution Time**: Ongoing

## SLA per Priority

Each priority level has defined Service Level Agreements that specify:
- Initial response time expectations
- Resolution timeframes
- Communication protocols
- Escalation thresholds

SLAs ensure consistent service delivery and help manage stakeholder expectations across different priority levels.

## Escalation Rules

### Automatic Escalation
- P0 issues automatically escalate to management within 30 minutes
- P1 issues escalate after 2 hours
