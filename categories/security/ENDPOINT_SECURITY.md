# Endpoint Security

## Purpose

Define security expectations for company-managed user and administrative endpoints.

## Requirements

Endpoints SHOULD use supported software, timely security updates, strong authentication, device encryption where appropriate, screen locking, least privilege, malware or behavioral protection where justified, and centralized inventory or health visibility proportional to risk.

Sensitive administrative work should use stronger controls than ordinary low-risk activity.

## Data

Restricted information stored locally should be minimized and protected. Loss or theft of a device containing company information requires prompt reporting and impact assessment.

## Exceptions

Unsupported or unmanaged endpoints require explicit risk review before accessing sensitive systems or information.
