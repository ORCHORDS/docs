# Migration Verification Evidence

## Purpose

Require objective evidence that a material migration preserved intended data, behavior, and operational integrity.

## Requirements

Migration verification SHOULD define pre-change expectations, validation queries or checks, reconciliation criteria, error handling, rollback or forward-repair conditions, and post-change acceptance evidence.

A migration is not complete only because execution returned success.

Unexplained differences, partial completion, or silent data loss require explicit investigation and closure.
