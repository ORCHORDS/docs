# Reference Data Governance

## Purpose

Keep shared classifications, codes, enumerations, and reference values consistent across systems and reporting.

## Requirements

Material reference datasets SHOULD identify authoritative owner, definitions, approved values, change process, effective dates where relevant, and consumers affected by change.

Local copies or forks should not silently become independent sources of truth.
