# SOP: Project Dependency Review

1. Identify material external/cross-team dependencies and owners.
2. Record required outcome, needed-by condition, confidence, and constraints.
3. Verify dependency status with evidence rather than project-plan assumption alone.
4. Define fallback, mitigation, or sequencing change for uncertain dependencies.
5. Escalate when the dependency threatens material scope, timing, risk, or benefit.
6. Update the decision/risk record after meaningful change.

Use [Project Dependency Template](../templates/PROJECT_DEPENDENCY_TEMPLATE.md).
