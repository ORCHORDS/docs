# Deprecation Action Closure SOP

1. Review migration, communication, support, data, dependency, and retirement actions.
2. Confirm outstanding user or operational impacts have owners or approved treatment.
3. Verify the deprecated capability is no longer relied upon beyond accepted exceptions.
4. Record closure evidence and remaining obligations.
