# Break-Glass Review Recertification SOP

1. Review emergency-access ownership, approval, logging, review criteria, and follow-up expectations.
2. Test whether procedures remain current and sufficiently independent.
3. Correct obsolete or unowned steps.
4. Record recertification without publishing access mechanisms.
