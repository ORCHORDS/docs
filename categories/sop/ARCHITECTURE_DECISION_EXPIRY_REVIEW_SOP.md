# Architecture Decision Expiry Review SOP

1. Review material architecture decisions and recorded assumptions.
2. Test review triggers against current requirements, dependencies, support, and risk.
3. Confirm, supersede, or retire decisions whose assumptions changed.
4. Record rationale without publishing private architecture.
