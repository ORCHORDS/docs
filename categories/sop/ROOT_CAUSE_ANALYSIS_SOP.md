# SOP: Root Cause Analysis

## Trigger
Use when a material failure, recurrence, or systemic issue warrants deeper causal analysis.

## Procedure
1. Build a factual timeline and define the observed problem.
2. Separate trigger, direct cause, contributing factors, and latent conditions.
3. Gather evidence across technical, process, supplier, organizational, and human factors.
4. Generate plausible causal hypotheses.
5. Test hypotheses against evidence and counterexamples.
6. Identify controls/barriers that failed or were absent.
7. Select causes that explain the evidence without forcing a single-cause story.
8. Link causes to corrective actions and owners.
9. Define effectiveness checks.
