# SOP: Deprecation and Sunset

## Trigger
Use when retiring a material capability, interface, integration, or supported version.

## Procedure
1. Define scope, owner, reason, and target retirement point.
2. Identify affected users, dependencies, data, and security implications.
3. Define migration, export, replacement, or workaround where appropriate.
4. Set communication and support plan.
5. Track adoption or remaining dependency.
6. Restrict new use when appropriate.
7. Perform final data/access/integration cleanup.
8. Verify removal and update documentation.
