# Accessibility Testing

## Purpose

Define evidence-based accessibility verification for public digital content and user interfaces.

## Test layers

Depending on scope, testing SHOULD combine automated checks with manual keyboard review, zoom/reflow checks, focus behavior, semantic structure, contrast, form/error handling, and assistive-technology testing for important journeys.

Automated tools cannot establish full conformance because many accessibility requirements require human judgment.

## Risk-based coverage

Prioritize essential journeys, high-use components, authentication and transaction flows, newly introduced interaction patterns, and areas with prior accessibility defects.

## Evidence

Record scope, environment, methods, findings, severity, owner, and retest result.

See [Accessibility Testing SOP](../sop/ACCESSIBILITY_TESTING_SOP.md).
