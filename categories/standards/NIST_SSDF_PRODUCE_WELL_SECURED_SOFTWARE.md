# NIST SSDF — Produce Well-Secured Software

## Purpose

Provide public governance guidance for the **Produce Well-Secured Software (PW)** practice group in NIST SP 800-218 SSDF Version 1.1.

## Baseline

Produce Well-Secured Software covers secure design, implementation, verification, dependency handling, build practices, and other activities intended to reduce vulnerabilities before release.

## Governance guidance

- define and review security requirements and threat considerations during design;
- apply secure coding practices appropriate to the technology and risk;
- review or analyze human-written and generated code for security-relevant defects;
- verify third-party components and dependencies before and during use;
- perform risk-based software testing and vulnerability analysis before release;
- protect build processes against unintended or unauthorized inputs;
- document residual security risks and approved exceptions before release.

## Verification

Confirm that security activities are integrated into the actual development workflow, findings are tracked to disposition, dependencies are known, and release decisions are supported by current verification evidence.
