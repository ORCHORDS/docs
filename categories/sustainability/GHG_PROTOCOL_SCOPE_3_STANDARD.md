# GHG Protocol Scope 3 Standard

## Purpose

Provide public governance guidance for accounting and managing indirect greenhouse gas emissions across an organization’s value chain.

## Baseline

The GHG Protocol Corporate Value Chain (Scope 3) Standard provides a corporate-level framework for identifying, calculating, and reporting value-chain emissions and for identifying reduction opportunities and supplier engagement priorities.

## Governance guidance

- Screen relevant Scope 3 categories before deciding which sources are material to detailed calculation.
- Define boundaries, calculation methods, data-quality expectations, and exclusions for each reported category.
- Prefer supplier-specific or activity data when it materially improves decision usefulness and reliability.
- Document estimates, assumptions, emission factors, allocation methods, and data gaps.
- Avoid double counting within the organization’s own inventory methodology.
- Separate measured reductions from changes caused only by methodology, boundaries, or data quality.
- Reassess material categories as business models, suppliers, products, or transport patterns change.

## Verification

Confirm that reported categories, exclusions, calculation approaches, and data quality are documented and that material Scope 3 claims can be traced to retained evidence.
