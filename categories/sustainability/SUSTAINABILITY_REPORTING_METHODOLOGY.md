# Sustainability Reporting Methodology

Sustainability reporting should state reporting scope, period, materiality approach, source hierarchy, calculation methods, significant estimates, restatements, and limitations.

Framework references must distinguish guidance used from formal conformance. External assurance must not be implied unless a current assurance engagement explicitly supports the statement.
