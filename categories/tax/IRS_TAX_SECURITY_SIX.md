# IRS Tax Security Six

## Purpose

Provide public governance guidance based on the IRS and Security Summit “Security Six” cybersecurity measures for tax professionals handling taxpayer information.

## Baseline

The IRS Tax Security 2.0 checklist identifies six foundational measures for tax practices:

1. anti-malware or anti-virus protection;
2. firewall protection;
3. multi-factor authentication when available;
4. backup software or services;
5. drive encryption;
6. secure virtual private network use for remote connections where appropriate.

## Governance guidance

- Treat the Security Six as a baseline, not a complete security program.
- Define ownership for configuration, monitoring, updates, and exception handling.
- Verify that backup copies are recoverable rather than assuming successful backup jobs are sufficient.
- Apply encryption and access controls according to the sensitivity of taxpayer data.
- Prefer phishing-resistant or stronger authentication methods where supported by the relevant service.
- Review remote-access methods and discontinue unnecessary exposure.

## Evidence examples

Evidence may include endpoint-protection status, firewall configuration, MFA enrollment, tested backup-restoration records, encryption status, remote-access configuration, and documented exceptions.

## Verification

Confirm that each adopted measure is operating on in-scope systems and that exceptions are documented and risk-assessed. Do not represent the six measures alone as complete legal or cybersecurity compliance.
