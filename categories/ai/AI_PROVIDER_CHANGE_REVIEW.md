# AI Provider Change Review

## Purpose

Reassess risk when a material AI provider changes model behavior, terms, data handling, security posture, supported controls, or service characteristics.

## Requirements

Material provider changes SHOULD be assessed for evaluation validity, privacy, security, contractual obligations, transparency, availability, cost, fallback, and user-impact implications.

A vendor label remaining the same does not mean the underlying risk profile is unchanged.
