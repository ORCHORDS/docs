# Support

## Where to go

| Need | Route |
| --- | --- |
| Something in a document is wrong, outdated, unclear, or missing | [Open a documentation issue](https://github.com/ORCHORDS/docs/issues/new?template=doc_issue.yml) |
| Security-sensitive finding | [SECURITY.md](./SECURITY.md) — never a public issue |
| General question about this repository or its content | `crm@orchords.com` |

## What this repository supports

This repository publishes ORCHORDS company documentation — policies,
standards, and procedures as public expectations. Maintainers triage
documentation issues and factual corrections.

This is not a product support channel. Customer or product support for
ORCHORDS services is handled through the official ORCHORDS contact channels,
not through this repository.

## Response expectations

Issues are triaged as maintainer capacity allows; there is no guaranteed
response time or service level. Security reports follow the process and
priorities described in [SECURITY.md](./SECURITY.md).
