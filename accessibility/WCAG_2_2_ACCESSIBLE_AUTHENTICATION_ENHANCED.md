# WCAG 2.2 Accessible Authentication (Enhanced)

Source: https://www.w3.org/TR/WCAG22/#accessible-authentication-enhanced

WCAG 2.2 Success Criterion 3.3.9 is Level AAA. It strengthens accessible-authentication expectations beyond the Level AA minimum criterion.

## Governance

- Prefer authentication methods compatible with password managers, copy/paste, passkeys, and other assistance mechanisms.
- Avoid authentication steps that depend on memory, puzzles, object recognition, or user-supplied-image recognition unless the criterion's permitted alternative/mechanism applies.
- Evaluate MFA and recovery flows as part of the same authentication journey; an accessible primary login does not compensate for an inaccessible recovery path.
- Do not block paste into credential fields without a documented, evidence-based reason.

## Claims boundary

Meeting this criterion for a particular authentication flow does not establish WCAG AAA conformance for a site or product.
