# Secure Remote Access

## Purpose

Set baseline protections for remote access to company-managed information and systems.

## Requirements

Remote access MUST use approved authenticated channels and protections appropriate to the sensitivity of the destination.

Controls SHOULD include strong authentication for privileged access, encrypted transport, managed-device or device-posture requirements where justified, bounded session lifetime, and monitoring for suspicious access.

Direct exposure of administrative services to broad untrusted networks should be avoided where safer access paths are available.

## Untrusted environments

Personnel must take reasonable precautions against shoulder surfing, device theft, insecure shared computers, and accidental disclosure in public locations.

## Exceptions

Temporary emergency access must be time-bounded, owned, and reviewed after use.
