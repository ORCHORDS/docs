# Defect Escape Analysis

## Purpose

Learn why material defects reached users or later lifecycle stages without converting every defect into process bureaucracy.

## Review

For material escapes, assess where detection was reasonably possible, why existing prevention/detection did not work, whether test assumptions were wrong, and whether similar defects could exist elsewhere.

Corrective action should improve the system rather than only adding a one-off test when the contributing cause is broader.

See [Defect Escape Review SOP](../sop/DEFECT_ESCAPE_REVIEW_SOP.md).
