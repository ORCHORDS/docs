# DMA end-user data portability and continuous access

**Issue:** DMA Article 6 portability duties apply to designated gatekeepers and listed core platform services, not every platform.
**Date:** 2026-08-18
**Author:** ORCHORDS
**Status:** documented

## Controls and implementation

Map designation/service/data, authenticated export and continuous access, third-party authorization, security and revocation.

## Tests

Test completeness, latency, continuity, revocation, third-party abuse, format documentation.

## Gotchas

Portability scope and real-time access are legal questions; do not export other users' data.
