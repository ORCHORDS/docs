# Privacy-Protective Defaults

## Purpose

Reduce privacy risk by making the ordinary/default path collect, expose, and retain no more personal data than the intended purpose reasonably requires.

## Requirements

Design SHOULD consider minimum fields, least disclosure, retention defaults, visibility/audience, analytics/telemetry necessity, exportability, deletion, and user understanding before optional expansion.

A default is not privacy-protective merely because users can later discover a setting to reduce collection or exposure.
