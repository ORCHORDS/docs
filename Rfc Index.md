# RFC Index

> Companion to [`RFC-XXX-template.md`](./RFC-XXX-template.md). Each RFC is a copy
> of the template with all sections filled in. This index tracks every RFC the
> team has filed.

## Conventions

- **File name:** `RFC-XXX-<short-title>.md` where `XXX` is the next number from this index (no gaps, no re-use).
- **State machine:** Draft → Under Review (1-week PR window) → Accepted / Accepted-with-changes / Rejected / Deferred.
- **Owner:** the RFC author; **sponsor** is a domain lead or the CTO.
- **Decision-maker:** Kirk Beka (CTO) for most RFCs; Mooned Dev (CEO) for engine-level architectural changes.

## How to add a new RFC

1. Copy `RFC-XXX-template.md` to `RFC-NNN-<short-title>.md` (use the next free number).
2. Fill in the front-matter table and every numbered section. The PR description must link back to the new file.
3. Open a PR. The 1-week comment window starts on PR open.
4. Update this index row with status as the discussion progresses.
