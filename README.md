**Independent software studio founded in 2025.**

## Public-repository standard

This repository is intentionally **public-safe**. It may describe principles, responsibilities, controls, decision criteria, reusable procedures, standards, and public evidence. It must not expose product-specific implementation details, deployment topology, credentials, private endpoints, customer information, internal identifiers, banking/tax records, private transaction information, personal data, facility-security details, or unannounced work.

## Evidence language

Statements about controls use these levels:

- **Required** — policy expectation.
- **Implemented** — supported by current evidence.
- **Planned** — approved but not yet implemented.
- **Not applicable** — formally assessed outside scope.

Never present a planned control as implemented or imply certification, audit results, service capability, transaction outcome, tax position, liquidity condition, or security guarantee without current evidence.

## Documentation workflow

Authorized routine maintenance is performed directly on **`main`**. Feature branches and pull requests are not required for routine documentation growth and maintenance.

Every change must still be:

- narrowly scoped;
- checked against existing related files for duplication;
- verified against current primary or authoritative sources where factual claims are involved;
- reviewed for public-safety and sensitive-data boundaries;
- synchronized with the affected README/index when a new page is added.

See [CONTRIBUTING.md](./CONTRIBUTING.md) and [Document Control](./governance/DOCUMENT_CONTROL.md).
