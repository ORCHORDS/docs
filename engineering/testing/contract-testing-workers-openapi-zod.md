# Contract Testing Workers APIs Against OpenAPI Spec with Zod

Date: 2026-08-23 / Author: example.com / Status: production

---

## Symptom / Use-case

Your Workers API has an OpenAPI 3.1 spec (generated by Hono's `@hono/zod-openapi` or
maintained by hand). Over time, code diverges from the spec: a response field is
renamed, a required parameter becomes optional, or an error shape changes. Integration
tests catch runtime errors but not shape drift. You want a Vitest test suite that
reads the OpenAPI spec, derives Zod schemas from it, and then asserts that real Worker
responses validate against those schemas — failing on the first deviation.

## Context

The contract testing approach here uses:
- `openapi-zod-client` or `zod-from-openapi` to convert OpenAPI schemas to Zod validators
- `@cloudflare/vitest-pool-workers` to run the Worker under test
- `SELF.fetch()` to call the running Worker endpoint
- Zod's `.safeParse()` to produce structured, diff-friendly failures

This approach sits between unit tests (which mock everything) and Pact-style consumer-
driven contracts (which involve a separate broker). It is purely server-side: the spec
is the contract, and the Worker must honour it.

## Parsing the OpenAPI Spec into Zod Schemas

```typescript
// test/helpers/openapi-to-zod.ts
import fs from "node:fs/promises";
import path from "node:path";
import { z } from "zod";

// Minimal OpenAPI 3.1 schema-to-Zod converter (extend as needed).
type OApiSchema = Record<string, unknown>;

export function oapiSchemaToZod(schema: OApiSchema): z.ZodTypeAny {
  if (schema.type === "object" || schema.properties) {
    const shape: Record<string, z.ZodTypeAny> = {};
    const props = (schema.properties as Record<string, OApiSchema>) ?? {};
    const required = (schema.required as string[]) ?? [];
    for (const [key, val] of Object.entries(props)) {
      const fieldSchema = oapiSchemaToZod(val);
      shape[key] = required.includes(key) ? fieldSchema : fieldSchema.optional();
    }
    return z.object(shape);
  }
  if (schema.type === "array") {
    return z.array(oapiSchemaToZod(schema.items as OApiSchema));
  }
  if (schema.type === "string") return schema.format === "date-time" ? z.string().datetime() : z.string();
  if (schema.type === "integer" || schema.type === "number") return z.number();
  if (schema.type === "boolean") return z.boolean();
  if (schema.$ref) return z.unknown(); // Resolve $ref externally if needed.
  return z.unknown();
}

export interface OpenApiSpec {
  paths: Record<string, Record<string, { responses: Record<string, { content?: Record<string, { schema: OApiSchema }> }> }>>;
  components?: { schemas?: Record<string, OApiSchema> };
}

export async function loadSpec(specPath: string): Promise<OpenApiSpec> {
  const raw = await fs.readFile(path.resolve(specPath), "utf8");
  return JSON.parse(raw) as OpenApiSpec;
}
```

## Contract Test Fixture

```typescript
// test/helpers/contract-fixture.ts
import { loadSpec, oapiSchemaToZod, OpenApiSpec } from "./openapi-to-zod";
import { z } from "zod";

export interface EndpointContract {
  method: string;
  path: string;
  statusCode: number;
  responseSchema: z.ZodTypeAny;
}

export async function extractContracts(specPath: string): Promise<EndpointContract[]> {
  const spec = await loadSpec(specPath);
  const contracts: EndpointContract[] = [];

  for (const [urlPath, methods] of Object.entries(spec.paths)) {
    for (const [method, operation] of Object.entries(methods)) {
      for (const [status, response] of Object.entries(operation.responses)) {
        const jsonContent = response.content?.["application/json"];
        if (!jsonContent?.schema) continue;
        contracts.push({
          method: method.toUpperCase(),
          path: urlPath,
          statusCode: parseInt(status, 10),
          responseSchema: oapiSchemaToZod(jsonContent.schema),
        });
      }
    }
  }
  return contracts;
}
```

## Writing the Contract Tests

```typescript
// test/openapi-contract.test.ts
import { SELF } from "cloudflare:test";
import { describe, it, expect, beforeAll } from "vitest";
import { extractContracts, EndpointContract } from "./helpers/contract-fixture";
import path from "node:path";

const SPEC_PATH = path.resolve(__dirname, "../openapi.json");
const BASE_URL = "https://example.com";

// Request factories per path — maps OpenAPI path templates to real test requests.
const requestFactory: Record<string, (method: string) => Request> = {
  "/users": (method) =>
    new Request(`${BASE_URL}/users`, {
      method,
      headers: { authorization: "Bearer test-token" },
    }),
  "/users/{id}": (method) =>
    new Request(`${BASE_URL}/users/1`, {
      method,
      headers: { authorization: "Bearer test-token" },
    }),
  "/posts": (method) =>
    new Request(`${BASE_URL}/posts`, {
      method,
      headers: {
        "content-type": "application/json",
        authorization: "Bearer test-token",
      },
      body: method === "POST" ? JSON.stringify({ title: "Hello", body: "World" }) : undefined,
    }),
};

describe("OpenAPI contract compliance", () => {
  let contracts: EndpointContract[];

  beforeAll(async () => {
    contracts = await extractContracts(SPEC_PATH);
    expect(contracts.length).toBeGreaterThan(0);
  });

  it("has at least one contract per documented path", async () => {
    const paths = [...new Set(contracts.map((c) => c.path))];
    expect(paths).toContain("/users");
    expect(paths).toContain("/users/{id}");
  });

  it("validates each endpoint response against its schema", async () => {
    const violations: string[] = [];

    for (const contract of contracts) {
      const factory = requestFactory[contract.path];
      if (!factory) continue; // Skip undocumented test paths.

      const response = await SELF.fetch(factory(contract.method));
      if (response.status !== contract.statusCode) continue; // Only validate matching status.

      const body = await response.json();
      const result = contract.responseSchema.safeParse(body);

      if (!result.success) {
        violations.push(
          `${contract.method} ${contract.path} [${contract.statusCode}]: ` +
            result.error.issues.map((i) => `${i.path.join(".")} — ${i.message}`).join(", ")
        );
      }
    }

    expect(violations).toEqual([]);
  });
});
```

## Inline Schema Snapshot Contract

For teams that want a lighter approach without parsing the full spec:

```typescript
// test/response-shape.test.ts
import { SELF } from "cloudflare:test";
import { it, expect } from "vitest";
import { z } from "zod";

const UserSchema = z.object({
  id: z.number().int().positive(),
  email: z.string().email(),
  created_at: z.string().datetime(),
  role: z.enum(["admin", "member", "viewer"]),
});

const UsersListSchema = z.object({
  data: z.array(UserSchema),
  cursor: z.string().optional(),
  total: z.number().int(),
});

it("GET /users response matches schema", async () => {
  const res = await SELF.fetch("https://example.com/users", {
    headers: { authorization: "Bearer test-token" },
  });
  expect(res.status).toBe(200);
  const body = await res.json();
  const parsed = UsersListSchema.safeParse(body);
  expect(parsed.success, JSON.stringify(parsed.error?.issues)).toBe(true);
});
```

## Anti-patterns

- Writing the Zod schema by hand and the OpenAPI spec by hand independently. They will
  drift. Use `@hono/zod-openapi` or `zod-to-json-schema` so one is the source of truth.
- Validating only happy-path (200) responses. Error shapes (400, 404, 422) are just as
  much part of the contract and often the first to drift.
- Skipping nullable fields in the Zod schema. An API that starts returning `null` for
  a field will silently fail `.string()` without `nullable()` or `.optional()`.
- Parsing the spec inside each test case (slow). Load it once in `beforeAll`.

## Gotchas

- `$ref` pointers in the OpenAPI spec require a resolver (e.g., `json-schema-ref-parser`)
  before passing individual schemas to `oapiSchemaToZod`. The helper above returns
  `z.unknown()` for unresolved refs — add resolution before using in strict tests.
- OpenAPI `format: "date-time"` maps to `z.string().datetime()` only if your Worker
  actually returns ISO-8601. If it returns Unix timestamps, use `z.number()`.
- `SELF.fetch()` uses the Worker's actual request routing. If your Worker validates the
  auth header and returns 401, the contract test for 200 will never validate the schema.
  Provide valid test credentials in every request factory.
- `additionalProperties: false` in OpenAPI does not map directly to `z.object().strict()`.
  Add `.strict()` calls explicitly if you want to catch undocumented response fields.

## Verification

```bash
# Run with spec path overridable via env
OPENAPI_SPEC=./openapi.json npx vitest run test/openapi-contract.test.ts

# Fail fast on first violation
npx vitest run --bail 1 test/openapi-contract.test.ts
```

A passing run with no violations confirms the Worker's responses are spec-compliant.
