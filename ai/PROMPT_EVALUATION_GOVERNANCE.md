# Prompt Evaluation Governance

## Purpose

Treat material system prompts, instructions, policies, and routing logic as evaluated behavior-changing configuration.

## Requirements

Material prompt changes SHOULD have versioning, representative evaluation, abuse-case review, rollback capability, and acceptance criteria appropriate to consequence.

Prompt changes should not bypass normal AI change governance merely because no model weights or application code changed.
