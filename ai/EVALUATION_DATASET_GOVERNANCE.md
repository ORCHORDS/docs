# AI Evaluation Dataset Governance

## Purpose

Ensure evaluation examples are representative, appropriately sourced, protected, and maintained over time.

## Requirements

Material evaluation datasets SHOULD identify purpose, owner, source categories, sampling limitations, sensitive-data restrictions, labeling assumptions, change history, and known coverage gaps.

Evaluation data should not be quietly optimized to the current system in ways that hide regressions or reduce realism.
