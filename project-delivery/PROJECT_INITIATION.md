# Project Initiation

## Purpose

Confirm that a material project is worth starting and is sufficiently understood to begin responsibly.

## Minimum initiation record

Define problem or opportunity, intended outcomes, scope, exclusions, sponsor, owner, stakeholders, key milestones, dependencies, major assumptions, initial risks, resource expectations, acceptance measures, and required functional reviews.

Do not treat an approved idea as proof that delivery feasibility, security, privacy, legal, or operational readiness has been established.

See [Project Initiation SOP](../sop/PROJECT_INITIATION_SOP.md).
