# Project Risk, Issue, and Change Governance

## Purpose

Keep project uncertainty, active problems, and scope changes visible and owned.

## Definitions

- **Risk:** uncertain event or condition that could affect objectives.
- **Issue:** condition already affecting or requiring action.
- **Change:** proposed modification to approved scope, outcome, schedule, cost, responsibility, or material assumption.

## Requirements

Material items SHOULD have owner, impact, action or treatment, target date, status, and escalation criteria.

Changes should assess downstream effects before approval, including customer commitments, security/privacy, operations, cost, schedule, quality, and documentation.
