# paid-tier-security-upgrade-runbook

**Issue:** A domain already running the free security stack from `free-tier-domain-security-runbook.md` (proxied DNS + DNSSEC, Full-strict TLS, Free Managed Ruleset, 5 custom rules, 1 rate-limit rule, Bot Fight Mode, Tunnel + Access, email auth) is upgrading to a paid plan and needs to know exactly what to switch on, in what order, at which tier. This is the paid companion to the free-tier runbook: it covers only the deltas — what Pro ($20/mo annual), Business ($200/mo annual), and Enterprise (contract) unlock, what stays the same, and what is not worth paying for yet. Prices and plan limits verified against Cloudflare docs and the plans pages in August 2026; both change, so re-verify before budgeting. Sources: https://www.cloudflare.com/plans/ and https://developers.cloudflare.com/waf/.

## The upgrade ladder at a glance

1. **What changes, and what does not.** (all plans) The upgrade changes rule budgets and unlocks features; it does not change the base posture. Keep everything from the free-tier runbook proxied and on Full (strict). Unmetered L3/L4 and L7 DDoS protection is automatic on every plan including Free — you never "enable" it and never pay more for it (https://developers.cloudflare.com/ddos-protection/). The 100% uptime SLA only exists from Business up (1x service credits on Business, 10x standard / 25x premium on Enterprise); PCI DSS 4.0 attestation of compliance is Business+ (https://www.cloudflare.com/plans/).
2. **Pro, day one.** Deploy the Cloudflare Managed Ruleset, turn off Bot Fight Mode and turn on Super Bot Fight Mode (with a webhook skip rule), add a second rate-limit rule, expand to 20 custom rules and 10 IP lists, enable Zone Lockdown on admin paths, and publish branded custom error pages. Cost: $20/mo billed annually, $25 monthly.
3. **Business, when attack volume or compliance forces it.** Add the WAF attack score class rule, regex custom rules, 5 rate-limit rules with 10-minute windows and 1-day bans, NAT-aware counting, rate-limit cache exclusion, "likely automated" SBFM controls, OV/EV custom certificates, and the 100% uptime SLA. Cost: $200/mo annual, $250 monthly.
4. **Enterprise, when you have a security team and a contract.** Full attack score + per-vector scores, Bot Management, 100 rate-limit rules with JA3/JA4 counting characteristics, Logpush, Adaptive DDoS Protection, Magic Transit + Magic Firewall, Keyless SSL, account-level rulesets, tenants/Organizations, and the API Shield subscription. Custom pricing via account team.

## Pro, step 1 — deploy the managed WAF

1. **Cloudflare Managed Ruleset.** (min plan: Pro) The signature ruleset that replaces the narrow Free Managed Ruleset: broader CVE coverage for SQLi, XSS, RCE, WordPress/drupal plugin exploits, with per-rule action and sensitivity overrides. Setup: Security > WAF > Managed rules > Deploy next to "Cloudflare Managed Ruleset"; leave defaults, override specific rules only when false positives appear. Verify: send a synthetic SQLi probe (`/?q=' OR '1'='1`) and confirm a block/challenge in Security > Events attributed to the Cloudflare Managed Ruleset service. Then remove any free-stack custom rules the ruleset now covers. https://developers.cloudflare.com/waf/managed-rules/
2. **OWASP Core Ruleset (optional, cautious).** (min plan: Pro) The OWASP CRS 3.3.0, deployed at paranoia level PL1 with sensitivity threshold Medium (score 40). Cloudflare's own docs warn it is prone to false positives and of "marginal benefit" when you already run the Cloudflare Managed Ruleset. Setup: deploy from the same Managed rules page, keep PL1/Medium, and watch Events for a week before raising anything. Verify: Security > Events filtered by service = OWASP Core Ruleset; if >5% of matches are false positives, disable the noisy rule IDs rather than raising the threshold. https://developers.cloudflare.com/waf/managed-rules/reference/owasp-core-ruleset/configure-dashboard/
3. **Leaked credentials detection.** (min plan: Pro) Checks request bodies against known-breached credential pairs for endpoints you designate (supersedes the deprecated Exposed Credentials Check). Setup: enable under Security > Settings > Leaked credentials detection, scoped to your login endpoint. Verify: Cloudflare test credentials on the configured path trigger a `leaked-credential` match in Events. https://developers.cloudflare.com/waf/managed-rules/
4. **Custom rules budget: 5 to 20.** (min plan: Pro; counts include rules in custom rulesets in the `http_request_firewall_custom` phase) Rewrite the free-stack rules from regex-free `contains` hacks into proper expressions now that the budget allows. Regex itself stays Business+ — do not rely on `matches` yet. The Log action stays Enterprise-only, so keep using Count for canary rules. Setup: Security > WAF > Custom rules. Verify: rule list shows 20 available; test one canary rule with Count and read the counter in Security > Events. https://developers.cloudflare.com/waf/custom-rules/

## Pro, step 2 — bots: replace Bot Fight Mode with Super Bot Fight Mode

1. **Super Bot Fight Mode, replacing BFM.** (min plan: Pro) SBFM runs in the Ruleset Engine (`http_request_sbfm` phase), so unlike free BFM you get configurable actions per category and skip-action exceptions. Setup: Security > Bots > Super Bot Fight Mode — first toggle Bot Fight Mode OFF (they conflict), then set "Definitely automated" (bot score 1) to Block and configure "Verified bots" to Allow. Verify: Security > Events shows matches with the SBFM service; your uptime monitor keeps working. Details and the BFM/SBFM switch path: `bot-fight-mode-free-vs-super.md`. https://developers.cloudflare.com/bots/get-started/super-bot-fight-mode/
2. **Skip rule for webhooks and partners.** (min plan: Pro) The canonical fix for broken payment-processor callbacks. Setup: Security > WAF > Custom rules > create rule matching `ip.src in $payment_webhooks` (or the partner user-agent) with action Skip > All Super Bot Fight Mode rules, placed first. Verify: POST a Stripe test webhook event and get HTTP 200 from origin. https://developers.cloudflare.com/waf/feature-interoperability/
3. **Cloudflare Tunnel caveat.** (min plan: Pro) If the zone fronts services over Cloudflare Tunnel, keep SBFM "Definitely automated" on Allow or set a skip rule for tunnel connector traffic — blocking it fails connections with `websocket: bad handshake`. Setup: skip rule matching the connector's egress IPs or hostname. Verify: `cloudflared tunnel --url` handshake stays healthy in Zero Trust > Tunnels after enabling SBFM. https://developers.cloudflare.com/bots/get-started/super-bot-fight-mode/
4. **Static resource protection + Bot Analytics.** (min plan: Pro) SBFM extends optional protection to static file types and unlocks Bot Analytics (Security > Bots) showing scores over time. Setup: enable "static resource protection" in SBFM settings only if scrapers hit assets. Verify: Bot Analytics renders score distribution charts — this becomes your evidence base for a future Business/Enterprise attack-score rule. https://developers.cloudflare.com/bots/get-started/super-bot-fight-mode/

## Pro, step 3 — rate limiting and edge controls

1. **Second rate-limit rule.** (min plan: Pro — 2 rules vs Free's 1) Pro also expands the counting period to 1 minute (vs Free's 10-second window) and the mitigation timeout to 1 hour. Note: the current availability table lists Free at a 10-second period/timeout — Cloudflare has tightened free limits over time, so re-check the table and update older notes (including our free-tier runbook). Setup: keep the free login-brute-force rule; add a second on `/api/*` — e.g. `http.request.uri.path contains "/api/"`, 300 requests per 1 minute, Block, timeout 1 hour. Verify: `ab`/`hey` burst past the threshold and confirm HTTP 429s, then recovery after the timeout. https://developers.cloudflare.com/waf/rate-limiting-rules/
2. **Expression fields unlock.** (min plan: Pro) Rate-limit and custom rule expressions gain host, URI path, full URI, and query fields beyond Free's path + verified-bot set. Setup: scope rate limits per-hostname on multi-tenant zones. Verify: rule deploys with a hostname-scoped expression that Free rejected. https://developers.cloudflare.com/waf/rate-limiting-rules/
3. **Zone Lockdown.** (min plan: Pro — 3 rules) Allow-list access to specific URLs by IP/Country/ASN; everything else gets error 1006. Setup: Security > WAF > Tools > Zone Lockdown, target `/admin*` with your office egress IPs + VPN ASN. Verify: request from a non-listed IP gets Access denied 1006; listed IP passes. https://developers.cloudflare.com/waf/tools/zone-lockdown/
4. **Custom error pages (Custom Errors).** (min plan: Pro — 25 rules/assets; Business 50, Enterprise 300) Branded 4xx/5xx/1000-series block pages, GA April 2025 (formerly "Custom Pages"). Setup: Account home > Custom Errors, upload an HTML asset with `::CLOUDFLARE_ERROR_1000S_BOX::`, attach to error 403/429. Verify: trip a block rule with `curl -H "Accept-Encoding: identity"` and see the branded page (compressed requests keep Cloudflare's default). Origin error pages themselves remain Enterprise-only. https://developers.cloudflare.com/rules/custom-errors/
5. **Bigger tool budgets.** (min plan: Pro) IP/custom lists go 1 to 10 (10k items each; quota set by the highest plan in the account), User Agent Blocking 10 to 50, config rules 10 to 25. Setup: convert the free stack's inline IP lists into named lists referenced by custom rules. Verify: Security > WAF > Lists shows 10 available; rules referencing lists evaluate correctly (test one listed IP). https://developers.cloudflare.com/waf/tools/lists/ and https://developers.cloudflare.com/rules/configuration-rules/

## Business — attack score, regex, and compliance

1. **WAF attack score class rule.** (min plan: Business) Cloudflare's ML model scores every request 1-99; Business can use the class field only. Setup: Security > WAF > Custom rules > expression `cf.waf.score.class eq "attack"` (or `ne "clean"` for stricter coverage), action Managed Challenge first, Block after a week of review. Verify: SQLi probe returns a challenge and Events shows the rule match with the score class. Full `cf.waf.score` and per-vector fields are Enterprise-only. https://developers.cloudflare.com/waf/get-started/
2. **Regex in custom rules.** (min plan: Business) The `matches` operator unlocks in custom rule expressions. Setup: replace free-era `contains` chains with anchored regexes (e.g. `http.request.uri.path matches "^/(api|admin)/v[0-9]+/"`). Verify: rule deploys (Free/Pro reject `matches`), test paths match in Events. https://developers.cloudflare.com/waf/custom-rules/
3. **100 custom rules and 5 rate-limit rules.** (min plan: Business) Custom rule budget goes to 100; rate-limit rules to 5, with counting periods to 10 minutes and mitigation timeouts to 1 day. Setup: add per-endpoint rules — login (10/min), password reset (5/10min), search (60/min), API write (300/min), contact form (10/hour ≈ 10-minute windows tuned). Verify: each rule trips and recovers on schedule; track trip counts weekly to retune. https://developers.cloudflare.com/waf/rate-limiting-rules/
4. **NAT-aware counting and cache exclusion.** (min plan: Business) Counting characteristic gains "IP with NAT support" (distinguishes users behind shared NAT), and rate-limit rules can exclude cached hits from the count so popular content does not trip limits. Setup: switch the API rule's counting to NAT-aware when you serve carrier-grade NAT audiences; enable "exclude cached requests" on path-generic rules. Verify: cache hits stop counting — run a cached burst and confirm no 429s. https://developers.cloudflare.com/waf/rate-limiting-rules/
5. **"Likely automated" SBFM control.** (min plan: Business) Business unlocks the action for the "likely automated" category (bot score 2-29), not just "definitely automated" (score 1). Setup: Security > Bots — set Likely automated to Managed Challenge on HTML routes, Log on API routes first. Verify: Events show SBFM matches in the 2-29 band with your chosen action. https://developers.cloudflare.com/bots/get-started/super-bot-fight-mode/
6. **Custom certificates (OV/EV) and compliance posture.** (min plan: Business, purchased add-on) OV/EV edge certificates with RSA+ECDSA bundles are available to Business and Enterprise customers who purchase them; PCI DSS 4.0 attestation applies Business+. Setup: SSL/TLS > Edge Certificates > Order Advanced Certificate if OV/EV or PCI scope demands it. Verify: certificate on the apex shows the purchased OV/EV issuer. https://developers.cloudflare.com/ssl/edge-certificates/custom-certificates/ and https://www.cloudflare.com/plans/
7. **Spectrum for SSH/RDP/other TCP.** (min plan: Pro, selected protocols; all TCP/UDP on Enterprise) Proxy non-HTTP services through Cloudflare to hide origin ports and get WAF-grade L7 DDoS on them. Setup: Spectrum > Add app, point `ssh.example.com` TCP/22 at your origin. Verify: `ssh` to the Spectrum hostname connects; origin 22 firewalled to Cloudflare IPs only. https://developers.cloudflare.com/spectrum/get-started/
8. **Method, source IP, and user-agent fields in rate limits.** (min plan: Business) Rate-limit expressions gain method, source IP, and user-agent fields. Setup: scope a rule to `http.request.method in {"POST"}` with a lower threshold than GETs. Verify: GETs unaffected, POST bursts trip. https://developers.cloudflare.com/waf/rate-limiting-rules/

## SSL add-ons available from any paid tier

1. **Advanced Certificate Manager (ACM).** (min plan: any, $10/mo add-on — does not require Pro) Up to 50 covered hostnames per cert including multi-level wildcards (`*.*.example.com`), CA/validation/validity choice, delegated DCV for CNAME setups, custom trust store, per-hostname min TLS, cipher control, and Total TLS. Enterprise can buy ACM for up to 100 edge certs per zone. Setup: SSL/TLS > Edge Certificates > Order Advanced Certificate Manager. Verify: cert issues for the multi-level hostname Universal SSL never covered. https://developers.cloudflare.com/ssl/edge-certificates/advanced-certificate-manager/ and https://www.cloudflare.com/plans/
2. **Total TLS.** (min plan: any, requires ACM) Auto-issues a certificate for every DNS record, present and future. Setup: enable the Total TLS toggle once ACM is active. Verify: create a new subdomain record; a cert issues for it without action. https://developers.cloudflare.com/ssl/edge-certificates/additional-options/total-tls/
3. **Cloudflare for SaaS / Custom Hostnames.** (min plan: any — self-serve on all plans) If you serve other people's domains: 100 custom hostnames included, scalable to 50,000, $0.10 per additional hostname. Enterprise-only extras: mTLS on custom hostnames, custom CA/uploaded certs, wildcard custom hostnames, custom firewall rulesets (WAF for SaaS), custom metadata. Setup: SSL/TLS > Custom Hostnames > Add, have the customer add the validation CNAME. Verify: `curl https://customer.example.com` serves a cert with the customer's hostname as SAN. https://developers.cloudflare.com/cloudflare-for-platforms/cloudflare-for-saas/plans/
4. **Keyless SSL.** (min plan: Enterprise, paid add-on) Private keys never leave your infrastructure; Cloudflare terminates without them. TLS 1.3 is not supported on keyless certs. Setup: run `gokeyless` on your HSM/key server (TCP 2407) and register it with Cloudflare. Verify: certificate chain shows keyless termination; confirm the key server sees session traffic on 2407. https://developers.cloudflare.com/ssl/keyless-ssl/

## Enterprise — WAF, bots, and rate limiting at scale

1. **Full WAF attack score.** (min plan: Enterprise) `cf.waf.score` plus per-vector `cf.waf.score.sqli`, `cf.waf.score.xss`, `cf.waf.score.rce` (1-99; 100 = not evaluated). Setup: ask your account team to enable attack score detection, then build per-path rules — e.g. `http.request.uri.path contains "/search" and cf.waf.score.sqli lt 20` to Block. Verify: synthetic SQLi on `/search` blocks while the same probe on a marketing page only challenges. https://developers.cloudflare.com/waf/get-started/ and https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/cf.waf.score/
2. **Bot Management.** (min plan: Enterprise add-on — this is the boundary with SBFM) ML scoring exposed as `cf.bot_management.score` (1-99) in custom rules, detection IDs, JA3/JA4 fingerprints, and per-endpoint thresholds instead of SBFM's domain-wide categories. Setup: account team enables the subscription; write path-specific rules like `(http.request.uri.path contains "/api/" and cf.bot_management.score lt 30)`. Verify: Events show numeric scores per request; a curl without browser fingerprints scores low and gets challenged. https://developers.cloudflare.com/bots/
3. **Advanced Rate Limiting.** (min plan: Enterprise with Advanced RL) 100 rules, counting periods to 65,535 seconds, and counting characteristics beyond IP: query, host, headers, cookie, ASN, country, path, JA3/JA4 (with Bot Management), JSON body fields, and complexity-based counting that weights expensive requests. Setup: convert the login rule to count by header `X-Session-ID` instead of IP; add a complexity rule on GraphQL. Verify: same-IP different-session traffic counts separately (no false 429s behind corporate NAT). https://developers.cloudflare.com/waf/rate-limiting-rules/
4. **1,000 custom rules, Log action, account-level rulesets.** (min plan: Enterprise) Custom rule budget to 1,000; the Log action becomes available; account-level custom rulesets apply one ruleset across every zone; zone custom rulesets go to 10 (Pro 2, Business 5). Setup: Security > WAF > Account-level rulesets for org-wide blocks; use Log action for forensic capture of attack traffic. Verify: rule changes propagate to all zones (spot-check a second zone's Events). https://developers.cloudflare.com/waf/custom-rules/
5. **Sensitive Data Detection and bigger lists.** (min plan: Enterprise) SDD flags responses containing PII/secrets at the edge. Custom lists go to 1,000 lists of 500,000 items; hostname lists, ASN lists, and Managed IP Lists (threat intel feeds) are Enterprise-only. Setup: enable SDD on API routes; subscribe to Managed IP Lists and reference them in rules. Verify: SDD findings appear in Security Events; a rule referencing a managed list deploys. https://developers.cloudflare.com/waf/managed-rules/ and https://developers.cloudflare.com/waf/tools/lists/
6. **IP Access Rules by country.** (min plan: Enterprise) Blocking an entire country in IP Access Rules (as opposed to a WAF custom rule, which all plans can do) is Enterprise-only. Setup: IP Access Rules > add country block when under regional attack. Verify: probe from a VPN in that country gets 1006. https://developers.cloudflare.com/waf/tools/ip-access-rules/

## Enterprise — network, DDoS, logging, tenancy

1. **Magic Transit + Magic Firewall.** (min plan: Enterprise) Extends Cloudflare's network to your own IP prefixes (BGP announcement; new accounts get a single shared IPv4 anycast address by default) with Magic Firewall (network-layer policy firewall) and Advanced TCP/DNS Protection included. Setup: work with the account team; advertise your prefixes, migrate or BYO. Verify: prefix visible in a looking glass routing to Cloudflare; Magic Firewall analytics show flows. https://developers.cloudflare.com/magic-transit/
2. **Adaptive DDoS Protection.** (min plan: Enterprise, with the Advanced DDoS Protection subscription) ML baselines that auto-generate L7 rules against traffic surges diverging from your normal profile; L3/4 adaptive requires Magic Transit/Spectrum BYOIP. Managed-ruleset override budget also goes from 1 to 10, and filtered DDoS alerts unlock. Setup: account team enables; approve adaptive rules in dashboard review mode. Verify: adaptive rules appear as suggestions during a synthetic load test that mimics an anomalous surge. https://developers.cloudflare.com/ddos-protection/managed-rulesets/adaptive-protection/
3. **Logpush.** (min plan: Enterprise — the only plan with zone Logpush) Streaming of firewall, HTTP, DNS, and NET logs to S3/R2/GCS/Azure/etc., max 4 jobs per zone, roughly 100-250 compressed bytes per request (1M req/day ≈ 100-250 MB/day). Below Enterprise, Workers Trace Events Logpush via Workers Paid ($5/mo) is the poor man's pipeline. Setup: Analytics > Logpush > Create job > firewall_http_adaptive as the first feed. Verify: objects land in the bucket within minutes; job health stays green over 24h. https://developers.cloudflare.com/logs/logpush/
4. **API Shield subscription.** (min plan: Enterprise add-on) Endpoint Management and schema validation exist on all plans with tiered limits (Free 100 endpoints / Pro 250 / Business 500 / Enterprise-without-subscription 3,000 — Block-only below Enterprise), but API Discovery, JWT validation, mTLS, and sequence analytics need the Enterprise API Shield subscription (10,000+ endpoints). Setup: start with schema validation in Log mode on the discovered endpoints, flip to Block after a clean week. Verify: a malformed request logs then blocks per mode. https://developers.cloudflare.com/api-shield/plans/
5. **Tenants and Organizations.** (min plan: Enterprise) The Tenant API manages many customer zones programmatically; Organizations (public beta, Enterprise + MSSP/Distributor role) adds multi-tier account hierarchies — single-tier on Enterprise, up to 5 nested levels as MSSP. Setup: account team provisions tenant management; use the managed-accounts API to create customer zones. Verify: create a child zone via API and confirm config inheritance from account-level rulesets. https://developers.cloudflare.com/tenant/how-to/manage-accounts/ and https://developers.cloudflare.com/fundamentals/organizations/

## Cloudflare One paid seats (parallel ladder, not the zone plan)

1. **Standard seats at $7/user/month.** (Zero Trust plan, independent of zone plan) Free covers 50 users with ZTNA, Gateway DNS/HTTP filtering, and DEX. Standard adds CASB (SaaS app posture), DLP, and Remote Browser Isolation, plus 30-day Gateway log query and the 100% uptime SLA. Enterprise adds custom terms. Setup: Zero Trust dashboard > Plans; move IT staff first, then everyone. Verify: assign user 51 (fails on Free), connect a CASB integration, launch an RBI session. https://www.cloudflare.com/plans/zero-trust-services/
2. **Account limits that scale with seats.** (Free/Standard/Enterprise) Gateway 500 policies per type and 1,000 tunnels are flat across plans; DEX tests 10/30/50, remote captures 100/200/800/day, proxy endpoints 50/500, PAC files 50/1,000, list entries 1k/5k. DLP custom entries 25, EDM datasets 100k cells, datasets 1M cells; Enterprise can request raises. Setup: model your device count against proxy endpoints before a fleet rollout. Verify: dashboard plan page shows the new limits post-upgrade. https://developers.cloudflare.com/cloudflare-one/account-limits/

## What NOT to pay for yet

1. **ACM/Total TLS with one flat hostname set.** (skip below multi-level subdomains or CA requirements) Universal SSL covers the apex and first-level wildcards on full setups. Pay the $10/mo only when you need `*.*.example.com`, a specific CA, per-hostname min TLS, or delegated DCV on a CNAME setup. https://developers.cloudflare.com/ssl/edge-certificates/advanced-certificate-manager/
2. **Bot Management without an API business.** If SBFM's three categories cover your abuse profile and Bot Analytics shows mostly score-1 garbage, the Enterprise BM subscription buys per-path precision you will not write rules for. Revisit when you have endpoints where verified-looking bots do damage.
3. **Keyless SSL without a compliance mandate.** It exists for "private keys may never leave our HSM" requirements and costs operational complexity (gokeyless, port 2407, no TLS 1.3). No mandate, no need. https://developers.cloudflare.com/ssl/keyless-ssl/
4. **Magic Transit without your own IP space.** It advertises your prefixes; a zone-only web property has nothing to advertise. Relevant only with on-prem networks/BYOIP. https://developers.cloudflare.com/magic-transit/
5. **Logpush before a SIEM exists.** Enterprise-only anyway; the decision is Workers Paid trace events ($5/mo) for sampled visibility versus Enterprise Logpush for full logs. Buy when a compliance or IR process actually consumes them. https://developers.cloudflare.com/logs/logpush/
6. **Zero Trust paid seats under 50 users.** Gateway, Access, and DEX are free up to 50 users. Pay $7/user only for CASB/DLP/RBI needs. https://www.cloudflare.com/plans/zero-trust-services/
7. **OWASP CRS at high paranoia.** Do not buy Pro just for OWASP at PL2+; Cloudflare's docs flag false positives and marginal benefit over the Cloudflare Managed Ruleset. The managed ruleset plus a Business attack-score rule is the higher-value path. https://developers.cloudflare.com/waf/managed-rules/reference/owasp-core-ruleset/configure-dashboard/
8. **Enterprise for a low-attack surface.** DDoS is unmetered on every plan; the core WAF is Pro; attack score is Business. Enterprise buys team, SLA credits, and scale features — a blog or low-traffic SaaS without those needs wastes the contract. https://developers.cloudflare.com/ddos-protection/
