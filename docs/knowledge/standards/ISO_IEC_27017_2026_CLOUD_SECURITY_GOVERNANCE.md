# ISO/IEC 27017:2026 Cloud Security Controls Governance

## Status

ISO/IEC 27017:2026 is Edition 2 of the cloud-security control guidance and was published in July 2026. It replaces the withdrawn ISO/IEC 27017:2015 edition.

Documentation and assurance work SHOULD cite the 2026 edition when describing the current standard.

## Scope

ISO/IEC 27017 provides cloud-specific implementation guidance based on ISO/IEC 27002 and additional controls for cloud service customers and cloud service providers.

It applies across public, private, and hybrid cloud deployment models.

## Governance expectations

Cloud-security documentation SHOULD make the shared-responsibility boundary explicit. At minimum, evidence should identify:

- Which party operates each security control.
- Who manages privileged administrative access.
- How assets are returned or removed when cloud service use ends.
- How virtual environments are separated.
- How cloud administrative operations are monitored.
- How customer and provider incident responsibilities interact.
- Which contractual or regulatory requirements alter the baseline.

## Transition rule

References to ISO/IEC 27017:2015 SHOULD be reviewed and either:

1. updated to ISO/IEC 27017:2026, or
2. retained with an explicit historical reason.

A control mapping MUST NOT silently treat the withdrawn 2015 edition as the current edition.

## Relationship to other standards

Use ISO/IEC 27017 together with:

- ISO/IEC 27001 for the information security management system.
- ISO/IEC 27002 for general information security controls.
- ISO/IEC 27018 when a public-cloud provider processes PII.
- ISO/IEC 27701 when privacy information management controls are required.
