# NIST SP 800-53 MA-3.1 Inspect Tools Governance Profile

## Governed reference

- Control: **MA-3.1 — Inspect Tools**
- Family: Maintenance

## Governance requirements

1. Applicability must be tied to a defined baseline, profile, requirement, or risk decision.
2. Organization-defined parameters must be explicit and reviewable.
3. Implementation responsibility must distinguish direct, shared, and inherited controls.
4. Verification evidence must be separate from policy statements and planned work.
5. Exceptions must identify owner, rationale, compensating measures where relevant, and review trigger.
6. Material changes to scope, architecture, providers, data, or threats trigger re-evaluation.
7. Public statements must not imply certification solely because this profile exists.

## Review record

Record scope, applicability, parameters, ownership, inheritance, evidence, findings, exceptions, and next review trigger.
