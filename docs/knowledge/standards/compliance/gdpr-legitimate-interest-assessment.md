# gdpr-legitimate-interest-assessment

**Issue:** Documenting legitimate interest as a lawful basis under GDPR Article 6(1)(f)
**Date:** 2026-08-11
**Status:** documented

## Symptom / Context
Organizations processing personal data without consent need an alternative lawful basis. Legitimate interest (LI) requires a three-part balancing test before processing can begin.

## Pattern / Solution
Conduct a Legitimate Interest Assessment (LIA) before processing:

```
LIA Template
1. Purpose Test: Is the interest genuine, real, and legal?
2. Necessity Test: Is processing necessary? Could less data achieve the goal?
3. Balancing Test: Nature of data, reasonable expectations, impact on data subjects, safeguards.
Outcome: Document whether interests override data subject rights.
```

Store LIA records as evidence. Review annually or when processing changes.

## Gotchas
- LI cannot override fundamental rights — high-risk processing almost always fails the test
- Direct marketing is a potential LI (Recital 47) but still requires opt-out
- Cannot use LI for processing children data
- Supervisory authorities can challenge undocumented assessments
