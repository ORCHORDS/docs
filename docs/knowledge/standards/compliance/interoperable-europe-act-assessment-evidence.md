# Interoperable Europe Act Assessment Evidence

**Issue:** Regulation (EU) 2024/903 requires Union entities and public-sector bodies to assess cross-border interoperability before certain binding requirements or network/information-system decisions.

**Date:** 2026-08-18
**Author:** ORCHORDS
**Status:** draft

## Controls
- Define a change gate that identifies covered public-service and cross-border effects.
- Record affected services, legal/organizational/semantic/technical barriers, stakeholders, reusable solutions, costs, and outcome.
- Consult the Interoperable Europe Portal and prefer reusable solutions where suitable.
- Publish or provide the assessment as required while removing protected information.
- Link decisions, procurement requirements, interfaces, vocabularies, and follow-up work to the assessment.

## Verification
- Sample covered changes and trace trigger decision to completed assessment and publication.
- Test a cross-border user journey against identity, language, data, and interface findings.
- Reassess after material scope or architecture change.

## Gotchas
An interoperability assessment is not a generic architecture review. Scope depends on public-service decisions and cross-border interoperability effects.
