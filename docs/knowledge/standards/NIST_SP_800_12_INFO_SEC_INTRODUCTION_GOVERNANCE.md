# NIST SP 800-12 Introduction to Information Security Governance

## Purpose

NIST Special Publication 800-12 Revision 1, *An Introduction to Information Security* (June 2017), is NIST's introductory guide to information-security concepts, controls, and program management. The publication is a foundational reference that complements SP 800-53, SP 800-100, and the NIST Cybersecurity Framework (CSF). Profiles that govern an Information Security Management System or that need an introductory reference for non-specialist audiences should reference SP 800-12 Rev. 1 by version.

## Current context and source status

SP 800-12 Rev. 1 was published in June 2017 and supersedes the original 1995 version. As of September 2026, no successor revision is published. The 2017 revision reorganized the content around information-security concepts, controls, programme management, and emerging topics (cloud, mobile, supply chain). Profiles that reference SP 800-12 should call out the Rev. 1 publication date and the relationship to SP 800-100 (Information Security Handbook) and the current NIST RMF (SP 800-37 Rev. 2).

## Governance workflow and controls

1. Reference SP 800-12 Rev. 1 in onboarding material, awareness training, and the introductory sections of the ISMS policy.
2. Bind the ISMS policy to the current NIST RMF (SP 800-37 Rev. 2), the CSF, and the SP 800-53 control catalogue.
3. Treat SP 800-12 as informative rather than normative: the binding controls are in SP 800-53.
4. Use the SP 800-12 controls taxonomy as a sanity check against the organization's control list; missing families indicate a gap in the ISMS.
5. Document deviations with the approver, scope, expiration, compensating controls, and review schedule.

## Validation and evidence

- ISMS policy referencing SP 800-12 Rev. 1, SP 800-53 Rev. 5, SP 800-37 Rev. 2, and the current CSF.
- Information-security awareness training based on SP 800-12 introductory concepts.
- Control catalogue mapped to SP 800-12 controls taxonomy.
- Periodic review of the introductory material against current NIST publications.

Evidence that references SP 800-12 without binding to the SP 800-53 control catalogue does not establish a defensible ISMS.

## Failure correction

Common defects include introductory training that drifts from current NIST terminology, missing mapping between the SP 800-12 taxonomy and the organization's control catalogue, and stale references to superseded revisions. Corrective actions include annual review of training material, mandatory control-mapping maintenance, and a policy-update cadence tied to NIST publication updates.
