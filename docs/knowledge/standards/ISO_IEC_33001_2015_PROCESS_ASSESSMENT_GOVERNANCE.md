# ISO/IEC 33001:2015 Process Assessment Governance

## Purpose

ISO/IEC 33001:2015 is the framework for process assessment based on the ISO/IEC 330xx family. It defines concepts, terminology, and requirements for conducting a process assessment. Governance ensures that process assessments are conducted with documented methodology, that results are used to drive improvement, and that assessors meet competence requirements.

## Current context and source status

ISO/IEC 33001:2015 was published as the first edition, replacing ISO/IEC 15504-1:2004 and related parts. The standard is part of the ISO/IEC 330xx family that supports process quality assessment using process reference models such as ISO/IEC 12207 (software life cycle) and ISO/IEC 15288 (system life cycle). Verify the current ISO/IEC 33001 family structure before treating any clause identifier as a current requirement.

## Governance workflow and controls

### 1. Define the assessment scope

Define which processes are in scope, which organizational units are in scope, and the assessment purpose (capability determination, process improvement, or both). Document the scope.

### 2. Select a process reference model

Select a process reference model appropriate to the assessment scope. Common choices include ISO/IEC 12207 (software), ISO/IEC 15288 (systems), ISO/IEC 33020 (process measurement framework). Document the choice and version.

### 3. Select or develop a process assessment model

Use an existing process assessment model (PAM) where one exists for the chosen reference model. Where no PAM exists, develop one following ISO/IEC 33003.

### 4. Ensure assessor competence

Assessors MUST meet the competence requirements in ISO/IEC 33002. Document assessor competence, training, and experience. Use multiple assessors for an assessment to ensure reliability.

### 5. Conduct the assessment

Plan the assessment, gather evidence (interviews, document review, artifact review), rate the process instances against the PAM, and produce the assessment record.

### 6. Use assessment results

Use assessment results for capability determination, process improvement, supplier evaluation, or benchmarking. Document the use of results.

### 7. Maintain assessment records

Retain assessment records per the documented retention policy. Maintain assessment history to track improvement.

## Validation and evidence

- Assessment scope document.
- Process reference model selection.
- PAM selection or development.
- Assessor competence records.
- Assessment record per assessment.
- Improvement actions resulting from the assessment.

## Failure correction

Common defects include assessor competence gaps, assessments that don't drive improvement, and process reference models that don't match the work. Corrective actions include assessor training, an assessment-action linkage review, and an annual reference model currency review.

## Limitations

- Process assessment is resource-intensive; scope carefully.
- The standard does not guarantee business outcomes; capability is a means, not an end.
- Some processes (for example, exploratory research) are not well-modeled by process assessment.
- The standard does not prescribe specific tools.
