# NIST CSF 2.0 DE.AE-03: Make the Outcome Explicit

## Authoritative outcome

**DE.AE-03:** Information is correlated from multiple sources

## Reusable lesson

This outcome should be treated as an explicit review question when it is relevant to the system or organization, rather than assumed to be satisfied by tooling, policy language, or another control.

## Apply the lesson

1. Define the real scope before judging the outcome.
2. Inspect current technical, process, governance, or operational evidence.
3. Separate documented intent from verified behavior.
4. Record partial coverage and unresolved gaps instead of converting them into a pass.
5. Revisit the outcome when the underlying scope, threat environment, technology, suppliers, or mission materially changes.
