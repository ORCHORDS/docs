# Audit Event Coverage Review

## Procedure
1. Identify security-relevant event classes for each system.
2. Verify successful, failed, privileged, administrative, and security events are logged as required.
3. Check fields needed for attribution and investigation.
4. Ensure logs avoid unnecessary sensitive data.
5. Remediate material coverage gaps.

## Source basis
- NIST SP 800-53 Rev. 5 — AU family.
