# Remote Access Control Review

## Procedure
1. Inventory remote access mechanisms and gateways.
2. Verify authorization, MFA, encryption, and routing restrictions.
3. Review vendor and administrative access separately.
4. Confirm inactive paths and stale permissions are removed.
5. Test logging and monitoring of remote access events.
6. Track gaps through remediation to closure.

## Source basis
- NIST SP 800-53 Rev. 5 — AC and SC families.
