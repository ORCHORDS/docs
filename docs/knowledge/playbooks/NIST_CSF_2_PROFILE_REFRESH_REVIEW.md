# NIST CSF 2.0 Profile Refresh Review

## Purpose
Maintain a current CSF 2.0 target / current / gap profile and a tier assessment aligned to organisational context and risk strategy.

## Procedure
1. Re-confirm organisational context: mission, business objectives, critical services, geographies, regulatory scope.
2. Refresh the target profile using the enterprise / SMB / sector profile (e.g., Ransomware Risk Management: A Cybersecurity Framework 2.0 Profile) as the baseline; record CSF subcategory selections and tier.
3. Capture the current profile by surveying control owners: per subcategory, mark Implemented / Partially Implemented / Planned / Not Applicable; cite evidence references.
4. Produce the gap profile with remediation owners, target dates, and prioritisation based on risk tier (FIPS 199 / SP 800-60).
5. Re-confirm the GOVERN function deliverables (GV.OC, GV.RM, GV.RR, GV.PO, GV.OV, GV.SC) and confirm board-level oversight cadence.
6. Cross-walk CSF subcategories to NIST SP 800-53 Rev. 5 controls and to ISO/IEC 27002:2022 Annex A controls; reflect any sector overlays (e.g., NIST SP 800-171 Rev. 3).
7. Refresh the tier assessment (Partial / Risk-Informed / Repeatable / Adaptive) with explicit rationale per GV.OV-01 / ID.AM-04.
8. Schedule the next refresh on a defined cadence (annual baseline; ad-hoc on material change).

## Source basis
- NIST Cybersecurity Framework 2.0 (2024).
- NIST SP 800-53 Rev. 5; NIST SP 800-171 Rev. 3; ISO/IEC 27002:2022.
- NIST CSF 2.0 Ransomware Risk Management Profile.
