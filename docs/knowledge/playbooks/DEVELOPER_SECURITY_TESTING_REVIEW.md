# Developer Security Testing Review

## Procedure
1. Inventory required security testing in the development lifecycle.
2. Verify tests execute on relevant changes and cannot be silently bypassed.
3. Review defect triage, suppression, and remediation evidence.
4. Identify untested components and stale rules.
5. Track improvements to closure.

## Source basis
- NIST SP 800-53 Rev. 5 — SA and SI families.
