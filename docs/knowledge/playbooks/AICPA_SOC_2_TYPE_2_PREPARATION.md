# AICPA SOC 2 Type 2 Preparation

## Purpose
Prepare for an AICPA SOC 2 Type 2 examination per the 2017 Trust Services Criteria (revised 2022) covering the system description and the chosen TSC categories.

## Procedure
1. Update the System Description (DC100 supplement): services, components, infrastructure, software, people, processes, locations, and any complementary user-entity controls (CUEC) or complementary service-organisation controls (CSOC).
2. Confirm Trust Services Categories in scope: Security (mandatory); choose Availability, Processing Integrity, Confidentiality, or Privacy where relevant.
3. Map each Common Criterion (CC1.1 – CC9.2) and each Additional Criterion (A1.x Availability; C1.x Confidentiality; PI1.x Processing Integrity; P1–P8 Privacy) to internal control implementations and evidence.
4. Refresh the risk assessment (CC3.x), monitoring activities (CC4.x), and control activities (CC5.x) for the period.
5. Refresh logical and physical access controls (CC6.x), system operations (CC7.x), change management (CC8.x), and risk mitigation (CC9.x).
6. Run the readiness assessment: control walkthroughs, sample selection (rotational across the period), evidence collection.
7. Confirm subservice-organisation treatment: inclusive method (inclusive trust-services criteria coverage) or carve-out method (reliance on subservice SOC reports); refresh subservice SOC report inventory.
8. Engage the CPA firm for Type 2 examination; align period (typically 6–12 months) to customer MSA expectations.
9. Track findings (control deficiencies) and remediation through the audit cycle.

## Source basis
- AICPA TSP Section 100 (TSC 2017, revised 2022).
- AICPA SOC 2 Reporting (AT-C § 205, § 320); DC100 / DC200 supplements.
- COSO Internal Control — Integrated Framework (2013); Cloud Security Alliance CCM mapping.
