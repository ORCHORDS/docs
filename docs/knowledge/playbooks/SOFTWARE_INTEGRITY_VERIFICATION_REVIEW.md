# Software Integrity Verification Review

## Procedure
1. Identify software artifacts requiring integrity verification.
2. Review hashes, signatures, provenance, or trusted build evidence.
3. Verify failed integrity checks block or escalate appropriately.
4. Review third-party and release artifacts separately.
5. Track gaps through remediation.

## Source basis
- NIST SP 800-53 Rev. 5 — SI and SA families.
