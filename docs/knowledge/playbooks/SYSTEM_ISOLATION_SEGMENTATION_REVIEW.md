# System Isolation and Segmentation Review

## Procedure
1. Map zones, workloads, and required trust boundaries.
2. Review enforcement points and permitted cross-zone flows.
3. Test representative denied paths.
4. Identify flat-network or overly broad access.
5. Remediate and record justified exceptions.

## Source basis
- NIST SP 800-53 Rev. 5 — SC family.
