# Consent and Preference Review

1. Inventory consent and preference controls.
2. Trace each control to the processing it governs.
3. Test opt-in, opt-out, and withdrawal behavior.
4. Verify downstream propagation.
5. Record defects and corrective actions.
6. Re-test before closure.

Source: NIST SP 800-53 Rev. 5, PII Processing and Transparency.
