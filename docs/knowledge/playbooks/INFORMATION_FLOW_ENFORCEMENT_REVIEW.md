# Information Flow Enforcement Review

## Trigger
Run on cadence, after material change, or when evidence questions effectiveness.

## Steps
1. Define scope/owner.
2. Collect current evidence.
3. Compare with applicable NIST SP 800-53 outcome.
4. Record gaps/actions/dates.
5. Validate closure.

## Source
NIST SP 800-53 Rev. 5 / Release 5.2.0.
