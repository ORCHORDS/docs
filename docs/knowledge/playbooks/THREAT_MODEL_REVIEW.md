# Threat Model Review

## Procedure
1. Refresh assets, data flows, trust boundaries, and dependencies.
2. Revisit threat actors, capabilities, and attack paths.
3. Compare threats against current mitigations.
4. Prioritize gaps by realistic impact and likelihood.
5. Track design or control changes to closure.

## Source basis
- NIST SP 800-53 Rev. 5 — RA and SA families.
