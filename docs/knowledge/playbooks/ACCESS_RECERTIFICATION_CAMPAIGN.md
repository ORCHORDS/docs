# Access Recertification Campaign

## Purpose
Run a periodic review of active access so owners can confirm continued business need and remove stale privileges.

## Flow
1. Define scope and review window.
2. Export current identities, roles, groups, and privileged assignments.
3. Route each item to an accountable owner.
4. Record approve, reduce, revoke, or investigate decisions.
5. Verify removals and retain evidence.

## Evidence
Scope, reviewer, decision, completion date, exceptions, and verification result.

## Sources
NIST SP 800-53 Rev. 5 AC family; NIST SP 800-53A Rev. 5.
