# NIST SP 800-171 Rev 3 SSP Refresh

## Purpose
Refresh the System Security Plan (SSP) and Plan of Action & Milestones (POA&M) for environments handling Controlled Unclassified Information (CUI) under SP 800-171 Rev. 3.

## Procedure
1. Re-validate the CUI boundary and asset inventory: identify every system component where CUI is resident, processed, transmitted, or protected, including the boundary and any external service providers.
2. Re-baseline the 14 SP 800-171 Rev. 3 families (AC, AT, AU, AM, CM, IA, IR, MA, MP, PE, PS, RA, SA, SI) at the CUI boundary.
3. For each of the 97 requirements, capture:
   - Implementation status (Implemented, Partially Implemented, Planned, Not Applicable, Alternative).
   - NCO (Nonfederal Organisation Option) variable values where applicable.
   - Evidence references (policy / procedure / configuration / audit log).
4. Update the POA&M: severity, residual risk, milestone, owner, scheduled close date; align severity grading to DFARS 252.204-7012 incident-reporting impact.
5. Document any organisation-defined parameters with explicit values and rationale; cross-walk to NIST SP 800-53 Rev. 5 control catalog where helpful.
6. Apply the NIST SP 800-171A Rev. 3 assessment objectives and methods (examine / interview / test) to the SSP and POA&M; document the assessment cycle.
7. Capture change rationale (workforce, system, or process change affecting CUI) and revalidate SSP / POA&M after every material change.
8. Apply CMMC applicability (Level 1, 2, or 3) and any C3PAO engagement requirements where CMMC applies.

## Source basis
- NIST SP 800-171 Rev. 3 (May 2024).
- NIST SP 800-171A Rev. 3 (assessment guide).
- NIST SP 800-53 Rev. 5; CNSSI 1253; DFARS 252.204-7012.
