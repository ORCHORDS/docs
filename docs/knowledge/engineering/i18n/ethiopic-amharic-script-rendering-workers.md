# Ethiopic (Amharic) Script Rendering on Cloudflare Workers and Pages

- **Date:** 2026-08-23
- **Author:** example.com
- **Status:** production

## Symptom / Use-case

A platform serving users in Ethiopia and Eritrea needs to render Amharic (and Tigrinya) text in the Ethiopic script correctly in server-generated HTML, API responses, and PDF exports. Common failures include garbled syllable sequences, missing Ethiopic punctuation (፡ ። ፣), incorrect line-breaking between syllables, and font-subsetting pipelines that drop Ethiopic Unicode blocks (U+1200–U+137F). The content is generated by Cloudflare Workers and served via Pages with custom fonts stored in R2.

## Context

Ethiopic is an abugida: each character represents a consonant-vowel syllable (fidel). Amharic uses 231 core syllabic characters plus numerals (፩–፱) and punctuation. Unlike Arabic or Hebrew, Ethiopic is left-to-right and does not require the Unicode bidirectional algorithm. However, it has its own punctuation block, its own word-separator (`፡` U+1361), and line-breaking must not occur mid-fidel. The Ethiopic block sits at U+1200–U+137F; extended characters for other Ethiopian languages occupy U+1380–U+139F, U+2D80–U+2DDF, and U+AB01–U+AB2F. Font support outside the core block is sparse — verify your typeface covers the required codepoints.

## Font Delivery from R2 with Subsetting

```typescript
// src/font-worker.ts
// Serves subsetted Ethiopic font from R2, with Cache-Control for edge caching.

interface Env {
  FONT_BUCKET: R2Bucket;
}

const ALLOWED_FONTS = new Set([
  "noto-sans-ethiopic-subset.woff2",
  "abyssinica-sil-subset.woff2",
]);

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url      = new URL(request.url);
    const fontName = url.pathname.split("/").pop() ?? "";

    if (!ALLOWED_FONTS.has(fontName)) {
      return new Response("Not found", { status: 404 });
    }

    const object = await env.FONT_BUCKET.get(`fonts/ethiopic/${fontName}`);
    if (!object) {
      return new Response("Font not found", { status: 404 });
    }

    const headers = new Headers();
    headers.set("Content-Type", "font/woff2");
    headers.set("Cache-Control", "public, max-age=31536000, immutable");
    headers.set("Access-Control-Allow-Origin", "*");

    return new Response(object.body, { headers });
  },
};
```

```css
/* pages/styles/ethiopic.css */
@font-face {
  font-family: "EthiopicSans";
  src: url("/fonts/noto-sans-ethiopic-subset.woff2") format("woff2");
  font-display: swap;
  /* Declare only the Ethiopic Unicode ranges to avoid FOIT for Latin text */
  unicode-range:
    U+1200-137F,  /* Ethiopic core block */
    U+1380-139F,  /* Ethiopic Supplement */
    U+2D80-2DDF,  /* Ethiopic Extended */
    U+AB01-AB2F;  /* Ethiopic Extended-A */
}

.am, [lang="am"], [lang="ti"] {
  font-family: "EthiopicSans", "Nyala", "Noto Sans Ethiopic", sans-serif;
  line-height: 1.8;   /* Ethiopic syllables have larger descenders */
  word-break: keep-all; /* Prevent mid-word breaks */
}
```

## Server-Side Amharic Text Normalization in Workers

```typescript
// src/amharic-normalize.ts

/**
 * Amharic has orthographic variants for several fidel characters —
 * multiple code points map to the same phoneme.
 * Normalize to the canonical form before storing or searching.
 *
 * Common equivalences (per Ethiopian Amharic standardization):
 *  ሀ U+1200 ≡ ሃ U+1203  (ha — the ሀ form is canonical)
 *  አ U+12A0 ≡ ዐ U+12D0  (glottal — አ is canonical in modern Amharic)
 *  ሰ U+1230 ≡ ሠ U+1220  (se — ሰ is canonical)
 *  ጸ U+1338 ≡ ፀ U+1340  (tse — ጸ is canonical)
 */
const ETHIOPIC_CANONICAL_MAP: Map<string, string> = new Map([
  ["ሃ", "ሀ"], // ሃ → ሀ
  ["ዐ", "አ"], // ዐ → አ
  ["ሠ", "ሰ"], // ሠ → ሰ
  ["ፀ", "ጸ"], // ፀ → ጸ
]);

export function normalizeAmharic(text: string): string {
  return Array.from(text)
    .map(ch => ETHIOPIC_CANONICAL_MAP.get(ch) ?? ch)
    .join("");
}

/**
 * Ethiopic uses ፡ (U+1361 ETHIOPIC WORDSPACE) as a word separator
 * alongside ASCII space. Normalize wordspace to ASCII space for
 * tokenization in search pipelines.
 */
export function tokenizeAmharic(text: string): string[] {
  return text
    .replace(/፡/g, " ") // Ethiopic wordspace → ASCII space
    .replace(/[።፡፣፤፥፦]/g, " ") // Ethiopic punctuation → space
    .trim()
    .split(/\s+/)
    .filter(Boolean);
}
```

## Ethiopic Numeral Rendering

```typescript
// src/ethiopic-numerals.ts

/**
 * Ethiopic numerals (U+1369–U+1371) are used in traditional contexts
 * such as religious texts and official documents.
 * Arabic numerals are the norm for modern Amharic digital products,
 * but some apps offer a toggle.
 */
const ETHIOPIC_ONES  = ["", "፩","፪","፫","፬","፭","፮","፯","፰","፱"];
const ETHIOPIC_TENS  = ["", "፲","፳","፴","፵","፶","፷","፸","፹","፺"];
const ETHIOPIC_HUNDREDS = "፻";
const ETHIOPIC_TEN_THOUSAND = "፼";

export function toEthiopicNumeral(n: number): string {
  if (n <= 0 || !Number.isInteger(n)) {
    throw new RangeError("Ethiopic numerals support positive integers only");
  }
  if (n === 100) return ETHIOPIC_HUNDREDS;
  if (n === 10_000) return ETHIOPIC_TEN_THOUSAND;

  const ten_thousands = Math.floor(n / 10_000);
  const remainder1    = n % 10_000;
  const hundreds      = Math.floor(remainder1 / 100);
  const remainder2    = remainder1 % 100;
  const tens          = Math.floor(remainder2 / 10);
  const ones          = remainder2 % 10;

  let result = "";
  if (ten_thousands > 0) result += toEthiopicNumeral(ten_thousands) + ETHIOPIC_TEN_THOUSAND;
  if (hundreds > 0)      result += (hundreds > 1 ? toEthiopicNumeral(hundreds) : "") + ETHIOPIC_HUNDREDS;
  if (tens > 0)          result += ETHIOPIC_TENS[tens];
  if (ones > 0)          result += ETHIOPIC_ONES[ones];

  return result;
}

// toEthiopicNumeral(1)     → "፩"
// toEthiopicNumeral(25)    → "፳፭"
// toEthiopicNumeral(100)   → "፻"
// toEthiopicNumeral(2025)  → "፳፻፳፭"
```

## Anti-patterns

- Loading a full Noto Sans font family and relying on the browser to subset — this sends hundreds of kilobytes of font data; use `unicode-range` in `@font-face` and build server-side subsets with `pyftsubset` scoped to U+1200–U+137F.
- Using U+0020 (ASCII space) as the only tokenization boundary for Amharic — native text may use U+1361 (Ethiopic wordspace `፡`) as the separator, causing zero-token results in search pipelines.
- Assuming NFC normalization alone handles Ethiopic variants — Ethiopic variant fidel characters are distinct precomposed code points, not decomposable; NFC/NFD makes no difference. Apply the canonical map explicitly.

## Gotchas

- The Ethiopic Extended-B block (U+1E7E0–U+1E7FF) added in Unicode 14 for Gurage and other languages has near-zero browser font support as of 2026; if your users include speakers of those languages, fall back to image rendering or notify that the script is unsupported.
- Ethiopic text in `<title>` and `<meta description>` renders correctly in modern browsers but may appear as boxes in some email clients — include a Latin transliteration fallback for email subjects.

## Verification

```bash
# Check font subset covers the Ethiopic block
pyftsubset NotoSansEthiopic-Regular.ttf \
  --unicodes="U+1200-137F,U+1380-139F" \
  --flavor=woff2 \
  --output-file=noto-sans-ethiopic-subset.woff2

# Upload to R2
wrangler r2 object put FONT_BUCKET/fonts/ethiopic/noto-sans-ethiopic-subset.woff2 \
  --file ./noto-sans-ethiopic-subset.woff2

# Test normalization
node -e "
const { normalizeAmharic, tokenizeAmharic } = require('./dist/amharic-normalize');
console.log(normalizeAmharic('ሃ')); // → ሀ
console.log(tokenizeAmharic('ሰላም፡ አለ'));// → ['ሰላም', 'አለ']
"
```
