# loom-async-communication

**Issue:** Architectural explanations and code walkthroughs require synchronous meetings
**Date:** 2026-08-11
**Status:** documented

## Symptom / Context
Async teams in different timezones lose productivity waiting for meeting windows to explain technical context.

## Pattern / Solution
Use Loom for async video explanations. Record PR walkthroughs instead of in-person review sessions. Architecture decision explanations as 5-minute videos linked from ADRs. Loom transcribes automatically for searchability.

## Gotchas
- Keep Looms under 10 minutes — longer videos are skipped, not watched async
- Loom free tier limits recording length and storage — paid for team use
