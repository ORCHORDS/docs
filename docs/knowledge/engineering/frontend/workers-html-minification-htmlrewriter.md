# HTML Minification at the Edge Using HTMLRewriter in Workers

Date: 2026-08-24
Author: example.com
Status: production

---

## Symptom / Use-case

Static HTML pages generated by a CMS or SSG contain unnecessary whitespace, HTML comments, and unminified inline `<script>` and `<style>` blocks that inflate transfer size. You want to minify HTML at the Cloudflare edge on the way out — with no build-step changes — shaving 10–30% off first-byte transfer without touching the origin.

## Context

Cloudflare Workers sit in front of every response served from R2 or a backend origin. `HTMLRewriter` is a streaming SAX-like API that processes HTML without buffering the whole document in memory. It can remove whitespace text nodes, strip comments, normalise attribute quotes, and pass through the response as a stream — suitable for large HTML pages.

Limitation: `HTMLRewriter` cannot minify inline `<script>` content (it sees text chunks, not an AST). Inline JS minification requires buffering and a JS parser — impractical in a Worker for large scripts. The pattern below minifies whitespace inside `<script>` blocks with a simple regex approach, acceptable for configuration-style inline scripts.

## Solution

### 1. Core Minification Worker

```typescript
// worker/src/minify.ts

export interface MinifyOptions {
  stripComments: boolean;
  collapseWhitespace: boolean;
  normaliseAttributes: boolean;
  minifyInlineStyle: boolean;
  bypassSelectors: string[];   // e.g. ['pre', 'code', 'textarea']
}

const DEFAULTS: MinifyOptions = {
  stripComments: true,
  collapseWhitespace: true,
  normaliseAttributes: true,
  minifyInlineStyle: true,
  bypassSelectors: ['pre', 'code', 'textarea', 'script[type="application/ld+json"]'],
};

/**
 * Apply HTMLRewriter-based minification to an HTML Response.
 * Returns a new streaming Response — does NOT buffer the full document.
 */
export function minifyHtml(
  response: Response,
  opts: Partial<MinifyOptions> = {}
): Response {
  const options = { ...DEFAULTS, ...opts };

  // Track whether the current text node is inside a bypass element
  let insideBypass = false;
  let insideStyle = false;
  let insideScript = false;

  let rewriter = new HTMLRewriter();

  // --- Bypass zones: pre, code, textarea ---
  for (const sel of options.bypassSelectors) {
    rewriter = rewriter.on(sel, {
      element() { insideBypass = true; },
    });
    // onEndTag via element handler
    rewriter = rewriter.on(sel, {
      element(el) {
        insideBypass = true;
        el.onEndTag(() => { insideBypass = false; });
      },
    });
  }

  // --- Comment stripping ---
  if (options.stripComments) {
    rewriter = rewriter.onDocument({
      comments(comment) {
        // Preserve IE conditional comments and server-side markers
        const text = comment.text.trim();
        if (text.startsWith('[if ') || text.startsWith('!') || text.startsWith('#')) return;
        comment.remove();
      },
    });
  }

  // --- Whitespace collapsing ---
  if (options.collapseWhitespace) {
    rewriter = rewriter.onDocument({
      text(chunk) {
        if (insideBypass) return; // preserve whitespace in pre/code

        // Collapse runs of whitespace to a single space; remove between-tag-only whitespace
        const collapsed = chunk.text
          .replace(/[\t\r\n]+/g, ' ')   // newlines → space
          .replace(/ {2,}/g, ' ');       // multiple spaces → one

        if (collapsed !== chunk.text) {
          chunk.replace(collapsed, { html: false });
        }
      },
    });
  }

  // --- Inline <style> minification ---
  if (options.minifyInlineStyle) {
    rewriter = rewriter.on('style', {
      element() { insideStyle = true; },
    });
    rewriter = rewriter.on('style', {
      element(el) {
        insideStyle = true;
        el.onEndTag(() => { insideStyle = false; });
      },
      text(chunk) {
        const minified = minifyCss(chunk.text);
        if (minified !== chunk.text) chunk.replace(minified, { html: false });
      },
    });
  }

  // --- Attribute quote normalisation ---
  // HTMLRewriter doesn't expose raw attribute strings; we use a document text
  // handler only as a fallback. True attribute normalisation requires the element handler.
  if (options.normaliseAttributes) {
    rewriter = rewriter.on('*', {
      element(el) {
        // Re-set each attribute; Cloudflare serialises them with double quotes
        for (const [name, value] of el.attributes) {
          el.setAttribute(name, value); // forces canonical double-quote serialisation
        }
      },
    });
  }

  return rewriter.transform(response);
}

/** Minimal CSS whitespace minifier (no AST — safe for most inline styles). */
function minifyCss(css: string): string {
  return css
    .replace(/\/\*[\s\S]*?\*\//g, '')      // strip /* comments */
    .replace(/\s*([{}:;,>+~])\s*/g, '$1')  // spaces around punctuation
    .replace(/;}/g, '}')                    // trailing semicolons before }
    .replace(/[\t\r\n]+/g, ' ')             // newlines → space
    .replace(/ {2,}/g, ' ')                 // collapse spaces
    .trim();
}
```

### 2. Main Worker Entry — Apply Minification to HTML Responses

```typescript
// worker/src/index.ts
import { minifyHtml } from './minify';

export interface Env {
  ASSETS: Fetcher;
  MINIFY_HTML: string; // 'true' | 'false' — toggled via Worker env var
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    // Serve the asset from R2/static binding
    const response = await env.ASSETS.fetch(request);

    // Only minify successful HTML responses
    const contentType = response.headers.get('Content-Type') ?? '';
    const isHtml = contentType.includes('text/html');
    const shouldMinify = env.MINIFY_HTML === 'true' && isHtml && response.status === 200;

    if (!shouldMinify) return response;

    // Clone headers, add Content-Encoding awareness
    const headers = new Headers(response.headers);
    // Strip Content-Length — minification changes body size
    headers.delete('Content-Length');
    // Mark that the response was processed
    headers.set('X-HTML-Minified', '1');

    const minified = minifyHtml(response, {
      stripComments: true,
      collapseWhitespace: true,
      normaliseAttributes: true,
      minifyInlineStyle: true,
      bypassSelectors: ['pre', 'code', 'textarea'],
    });

    // Return a new Response with merged headers
    return new Response(minified.body, {
      status: response.status,
      statusText: response.statusText,
      headers,
    });
  },
};
```

### 3. Size Measurement Middleware

```typescript
// worker/src/measure.ts

/**
 * Tee the response stream and measure byte count.
 * Use only in staging — doubles memory usage.
 */
export async function measureResponse(
  response: Response
): Promise<{ size: number; text: string }> {
  const text = await response.text();
  const size = new TextEncoder().encode(text).byteLength;
  return { size, text };
}
```

### 5. Testing Minification Output

```typescript
// tests/minify.test.ts
import { describe, it, expect } from 'vitest';
import { minifyHtml } from '../worker/src/minify';

function htmlResponse(body: string): Response {
  return new Response(body, { headers: { 'Content-Type': 'text/html' } });
}

describe('minifyHtml', () => {
  it('strips HTML comments', async () => {
    const r = minifyHtml(htmlResponse('<!-- comment --><p>Hello</p>'));
    expect(await r.text()).toBe('<p>Hello</p>');
  });

  it('collapses whitespace between tags', async () => {
    const r = minifyHtml(htmlResponse('<div>  \n  <span>A</span>  \n  </div>'));
    const text = await r.text();
    expect(text).not.toMatch(/\n/);
    expect(text).not.toMatch(/ {2,}/);
  });

  it('preserves whitespace inside <pre>', async () => {
    const input = '<pre>  indented\n  code  </pre>';
    const r = minifyHtml(htmlResponse(input));
    expect(await r.text()).toContain('  indented\n  code  ');
  });

  it('minifies inline styles', async () => {
    const r = minifyHtml(htmlResponse('<style>  body {  color: red;  }  </style>'));
    expect(await r.text()).toContain('body{color:red}');
  });

  it('preserves IE conditionals', async () => {
    const r = minifyHtml(htmlResponse('<!--[if IE]><p>IE</p><![endif]-->'));
    expect(await r.text()).toContain('[if IE]');
  });
});
```

## Implementation Details

- **Streaming, not buffering**: `HTMLRewriter.transform()` returns a streaming Response. The document is processed chunk by chunk, so a 500 KB HTML page never fully lands in Worker memory.
- **Comment preservation rules**: IE conditional comments (`<!--[if IE]>`), SSI markers (`<!--# include -->`), and Svelte/template markers starting with `!` or `#` are preserved. All others are removed.
- **Attribute re-serialisation**: Setting an attribute via `el.setAttribute(name, value)` causes Cloudflare's serialiser to output it with canonical double-quote wrapping. This normalises single-quoted and unquoted attributes from legacy HTML generators.
- **`Content-Length` removal**: After minification, the original `Content-Length` is wrong. Deleting it forces chunked transfer encoding. Browsers handle this correctly; proxies do too.
- **`Vary` header**: If minification is conditional on a request header, add `Vary` so caches store separate entries.

---

## Anti-patterns

- **Buffering with `.text()` before minification**: Defeats the streaming model and can OOM the Worker on large HTML (Workers have a 128 MB memory limit, but streaming is cheaper).
- **Minifying non-HTML responses**: Always check `Content-Type` before running `HTMLRewriter`. Applying it to JSON or binary responses corrupts them.
- **Aggressive whitespace removal inside `<script>` blocks**: Removing newlines inside multiline string literals or template literals breaks JS. The safe approach is only whitespace-collapsing CSS inside `<style>`.
- **Stripping ALL comments**: Knockout.js, Alpine.js, and some SSR frameworks use HTML comments as component boundaries. Check your stack before enabling unconditional comment removal.
- **Running minification on cached responses in Cloudflare Cache**: If the Worker runs after the cache (`cache.match`), the response may already be minified — double-minification is harmless but wastes CPU.

---

## Gotchas

- `HTMLRewriter` **does not support** XML or XHTML. XHTML self-closing tags (`<br/>`) are normalised to HTML5 (`<br>`). If your downstream expects XHTML, skip HTMLRewriter.
- The `onDocument` text handler fires for **every text node in the document**, including text inside SVG embedded in HTML. Test SVG-heavy pages.
- `chunk.replace()` with `{ html: false }` escapes HTML entities in the replacement string. Pass `{ html: true }` only if the replacement is known-safe HTML.
- HTMLRewriter processes comments via `onDocument.comments` — not via element handlers. There is no element-level comment handler.
- Workers executed via a `fetch` subrequest (e.g., `env.ASSETS.fetch`) return a standard `Response`. The response body is already a readable stream — never call `.text()` on it before passing to `HTMLRewriter.transform()`, or the stream will be consumed.
