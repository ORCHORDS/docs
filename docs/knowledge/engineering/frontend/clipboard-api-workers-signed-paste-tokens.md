# Clipboard API + Cloudflare Workers Signed Paste Tokens

Date: 2026-08-23 / Author: example.com / Status: production

---

**Symptom / Use-case:** You need to enforce that content copied from your app can only be pasted back into your app (or an authorized partner), or conversely, that paste operations in your app accept only content originating from your Workers backend — for DRM, tamper-evident data transfer, audit trails, or anti-scraping measures.

**Context:** The async Clipboard API (`navigator.clipboard`) can read/write arbitrary structured data. By embedding a short-lived HMAC signature generated by a Cloudflare Worker into the clipboard payload, the receiving app can verify origin, expiry, and integrity without a round-trip at paste time. The Worker mints the signed token on copy; the receiving endpoint validates it on paste (or the client verifies it synchronously using a public key with Web Crypto).

---

## Architecture Overview

```
Copy flow:  [User clicks Copy] → fetch /api/clip/sign → Worker mints HMAC token
             → write {data, sig, exp} to clipboard as text/plain + custom MIME type

Paste flow: [User pastes] → read from clipboard → extract token
             → Worker GET /api/clip/verify (or client-side HMAC verify)
             → accept or reject the payload
```

## Worker — Mint a Signed Clipboard Token

```typescript
// workers/clip.ts
import { Env } from './bindings';

const EXPIRY_SECONDS = 120;   // token valid for 2 min

async function hmac(secret: string, message: string): Promise<string> {
  const key = await crypto.subtle.importKey(
    'raw',
    new TextEncoder().encode(secret),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign']
  );
  const sig = await crypto.subtle.sign(
    'HMAC',
    key,
    new TextEncoder().encode(message)
  );
  return btoa(String.fromCharCode(...new Uint8Array(sig)));
}

export default {
  async fetch(req: Request, env: Env): Promise<Response> {
    const url = new URL(req.url);

    // POST /api/clip/sign  — mint token
    if (url.pathname === '/api/clip/sign' && req.method === 'POST') {
      const { payload } = await req.json<{ payload: string }>();
      const exp = Math.floor(Date.now() / 1000) + EXPIRY_SECONDS;
      const message = `${exp}:${payload}`;
      const sig = await hmac(env.CLIP_SECRET, message);
      return Response.json({ payload, exp, sig });
    }

    // GET /api/clip/verify?payload=…&exp=…&sig=…  — validate token
    if (url.pathname === '/api/clip/verify' && req.method === 'GET') {
      const payload = url.searchParams.get('payload') ?? '';
      const exp     = parseInt(url.searchParams.get('exp') ?? '0', 10);
      const sig     = url.searchParams.get('sig') ?? '';

      if (Math.floor(Date.now() / 1000) > exp) {
        return Response.json({ valid: false, reason: 'expired' }, { status: 401 });
      }
      const expected = await hmac(env.CLIP_SECRET, `${exp}:${payload}`);
      const valid = expected === sig;
      return Response.json({ valid, reason: valid ? 'ok' : 'invalid_sig' });
    }

    return new Response('Not Found', { status: 404 });
  },
};
```

## Browser — Copy with Signed Token

```typescript
// lib/clipboard.ts
export interface SignedClip {
  payload: string;
  exp:     number;
  sig:     string;
}

export async function copyWithSignature(text: string): Promise<void> {
  if (!navigator.clipboard?.writeText) {
    throw new DOMException('Clipboard write not supported', 'NotSupportedError');
  }

  const resp = await fetch('/api/clip/sign', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ payload: text }),
  });
  const token: SignedClip = await resp.json();

  // Embed token as JSON in the clipboard alongside human-readable text
  const encoded = JSON.stringify(token);

  // Prefer ClipboardItem for multi-type write (Chromium 101+)
  if (typeof ClipboardItem !== 'undefined') {
    await navigator.clipboard.write([
      new ClipboardItem({
        'text/plain':        new Blob([text],    { type: 'text/plain' }),
        'web application/x-signed-clip': new Blob([encoded], { type: 'web application/x-signed-clip' }),
      }),
    ]);
  } else {
    // Fallback: embed JSON in a comment appended to plain text
    await navigator.clipboard.writeText(`${text}\n<!-- SIGNED_CLIP:${encoded} -->`);
  }
}
```

## Browser — Paste with Verification

```typescript
// lib/clipboard.ts (continued)
export async function pasteWithVerification(): Promise<string> {
  if (!navigator.clipboard?.read) {
    throw new DOMException('Clipboard read not supported', 'NotSupportedError');
  }

  const items = await navigator.clipboard.read();

  for (const item of items) {
    // Try custom MIME type first
    if (item.types.includes('web application/x-signed-clip')) {
      const blob = await item.getType('web application/x-signed-clip');
      const token: SignedClip = JSON.parse(await blob.text());
      await assertValid(token);
      return token.payload;
    }

    // Fallback: extract embedded JSON comment from plain text
    if (item.types.includes('text/plain')) {
      const blob = await item.getType('text/plain');
      const raw  = await blob.text();
      const match = raw.match(/<!-- SIGNED_CLIP:(.+?) -->/);
      if (match) {
        const token: SignedClip = JSON.parse(match[1]);
        await assertValid(token);
        return token.payload;
      }
      // No token — accept as unsigned plain text (or reject per policy)
      return raw;
    }
  }
  throw new Error('No readable clipboard content');
}

async function assertValid(token: SignedClip): Promise<void> {
  const params = new URLSearchParams({
    payload: token.payload,
    exp:     String(token.exp),
    sig:     token.sig,
  });
  const resp = await fetch(`/api/clip/verify?${params}`);
  const { valid, reason } = await resp.json<{ valid: boolean; reason: string }>();
  if (!valid) throw new Error(`Clipboard token invalid: ${reason}`);
}
```

## Client-Side Verification with HMAC Public Key (Zero Round-Trip)

```typescript
// For lower-latency verification, expose a public HMAC key via Workers
// and verify in-browser with Web Crypto (symmetric key must be rotated
// server-side; use asymmetric ECDSA for true public verification).

export async function verifyLocally(
  token: SignedClip,
  sharedKey: CryptoKey   // pre-fetched and cached
): Promise<boolean> {
  if (Math.floor(Date.now() / 1000) > token.exp) return false;
  const message = `${token.exp}:${token.payload}`;
  const sigBytes = Uint8Array.from(atob(token.sig), (c) => c.charCodeAt(0));
  return crypto.subtle.verify(
    'HMAC',
    sharedKey,
    sigBytes,
    new TextEncoder().encode(message)
  );
}
```

## Anti-patterns

- **Storing the HMAC secret in the client bundle** — the secret must live only in `env.CLIP_SECRET` (a Worker secret set via `wrangler secret put CLIP_SECRET`); client-side HMAC is authentication theater without a key rotation strategy.
- **Using `navigator.clipboard.writeText()` for the token** — plain text gets sanitized by password managers and clipboard managers; use `ClipboardItem` with a custom MIME type to isolate the signature.
- **Long expiry windows** — a 2-minute expiry covers typical copy-paste latency; longer windows increase replay risk.
- **Not catching `NotAllowedError`** — clipboard read requires the `clipboard-read` permission which is only granted in the focused tab after a user gesture.

## Gotchas

- `ClipboardItem` with custom MIME types (`web …/…`) is limited to **Chromium 101+** and requires `chrome://flags/#clipboard-unsanitized-content` in some versions — test the plain-text fallback path.
- `navigator.clipboard.read()` requires the `clipboard-read` permission to be granted; prompt with `navigator.permissions.query({ name: 'clipboard-read' })` before calling.
- Workers `crypto.subtle` is synchronous-in-async but executes in the V8 isolate — HMAC operations are fast (<1 ms); no need for KV caching of tokens.
- `wrangler secret put CLIP_SECRET` sets the secret for **production**; for local dev use a `.dev.vars` file: `CLIP_SECRET=dev-only-not-secret`.
- The `Permissions-Policy: clipboard-read=(), clipboard-write=()` header (set in Cloudflare Pages `_headers`) blocks clipboard access in embedded iframes.

## Verification

```bash
# Set the secret locally
echo "CLIP_SECRET=my-local-dev-secret" >> .dev.vars

# Start Workers dev
wrangler dev

# Mint a token
curl -X POST http://localhost:8787/api/clip/sign \
  -H 'Content-Type: application/json' \
  -d '{"payload":"hello signed world"}'
# Returns: {"payload":"hello signed world","exp":1700001234,"sig":"...base64..."}

# Verify the token
curl "http://localhost:8787/api/clip/verify?payload=hello+signed+world&exp=1700001234&sig=...base64..."
# Returns: {"valid":true,"reason":"ok"}
```
