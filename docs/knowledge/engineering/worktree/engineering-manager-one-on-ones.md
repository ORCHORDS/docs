# engineering-manager-one-on-ones

**Issue:** 1-1 meetings become status updates that could have been Slack messages
**Date:** 2026-08-11
**Status:** documented

## Symptom / Context
An EM opens the 1-1 by asking "what are you working on?" The engineer recaps their Jira board. Thirty minutes pass. Nothing of developmental value was discussed. The engineer leaves feeling neither supported nor challenged.

## Pattern / Solution
1-1s are for the engineer's growth, not the manager's status update. Structure them accordingly.

**Cadence:** Weekly 30 min for junior engineers; biweekly 45 min for senior engineers

**Agenda ownership:** The engineer owns the agenda. Manager's role is to create space, ask questions, and follow up on commitments.

**Suggested weekly agenda template (shared doc, both update before the meeting):**
```
## [Engineer Name] 1-1 — [Date]

### Top of mind for me this week
(Engineer fills this in)

### Blockers / things I need from you
(Engineer fills this in)

### Career / growth topic this week
(rotating topics: skills, projects, feedback, goals)

### Manager follow-ups from last week
(Manager fills in what they committed to)

### Actions
- [ ] Engineer: …
- [ ] Manager: …
```

**Rotating growth topics (cycle through quarterly):**
- Skills: "What are you trying to get better at? How can I help?"
- Projects: "What kind of work do you want more of?"
- Feedback: "What feedback can I give you? What feedback do you have for me?"
- Goals: "Where do you want to be in 12 months? Are we on track?"
- Recognition: "What are you most proud of this quarter?"

**What managers should NOT do in 1-1s:**
- Provide status updates the engineer didn't ask for
- Dominate the conversation
- Use the 1-1 to deliver critical feedback without prior context

## Gotchas
- Canceling 1-1s frequently signals the engineer isn't a priority — protect this time
- If the engineer says "nothing to discuss," the manager needs to ask deeper questions
- The shared doc is the single source of truth; don't duplicate it in a separate notes app
