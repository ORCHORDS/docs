# Expo Workers R2 Image Upload Progress Tracking

Date: 2026-08-23 / Author: example.com / Status: production

---

## Symptom / Use-case

Users uploading photos (3–15 MB) see a spinner with no indication of progress. On slow connections they abandon. `expo-file-system` `uploadAsync` does not expose granular progress for presigned PUT requests. The solution is to obtain a presigned R2 URL from a Workers endpoint and drive the upload through `XMLHttpRequest` (or `fetch` with a `ReadableStream` wrapper), which fires `progress` events.

## Context

R2 presigned URLs are generated by Workers using the AWS S3 SDK (R2 is S3-compatible). The client uploads directly to R2 — Workers never proxies the file bytes. Progress events come from `XMLHttpRequest.upload.onprogress` inside Expo's JS runtime (Hermes supports XHR).

Upload flow:
```
App → Workers /upload/presign → R2 presigned PUT URL
App → PUT (with XHR progress) → R2 directly
App → Workers /upload/confirm → mark upload complete in D1
```

## Workers: Presign Endpoint

```typescript
// workers/src/upload/presign.ts
import { AwsClient } from 'aws4fetch';
import { Env } from '../types';

interface PresignRequest {
  filename: string;
  content_type: string;
  size_bytes: number;
}

const MAX_SIZE = 50 * 1024 * 1024; // 50 MB

export async function handlePresign(
  request: Request,
  env: Env
): Promise<Response> {
  const auth = request.headers.get('Authorization');
  if (!auth) return Response.json({ error: 'unauthorized' }, { status: 401 });

  const body = await request.json<PresignRequest>();

  if (body.size_bytes > MAX_SIZE) {
    return Response.json({ error: 'file_too_large' }, { status: 413 });
  }

  const objectKey = `uploads/${crypto.randomUUID()}/${body.filename}`;

  const aws = new AwsClient({
    accessKeyId: env.R2_ACCESS_KEY_ID,
    secretAccessKey: env.R2_SECRET_ACCESS_KEY,
    region: 'auto',
    service: 's3',
  });

  const url = new URL(
    `https://${env.R2_BUCKET_NAME}.${env.R2_ACCOUNT_ID}.r2.cloudflarestorage.com/${objectKey}`
  );

  // Presign a PUT valid for 15 minutes
  const signed = await aws.sign(
    new Request(url.toString(), {
      method: 'PUT',
      headers: { 'Content-Type': body.content_type },
    }),
    { aws: { signQuery: true, expiresIn: 900 } }
  );

  return Response.json({
    upload_url: signed.url,
    object_key: objectKey,
  });
}
```

## Workers: Confirm Upload

```typescript
// workers/src/upload/confirm.ts
export async function handleConfirm(
  request: Request,
  env: Env
): Promise<Response> {
  const { object_key, metadata } = await request.json<{
    object_key: string;
    metadata: Record<string, string>;
  }>();

  // Verify the object actually landed in R2
  const head = await env.R2_BUCKET.head(object_key);
  if (!head) {
    return Response.json({ error: 'object_not_found' }, { status: 404 });
  }

  // Record in D1
  await env.DB.prepare(
    `INSERT INTO uploads (object_key, size, content_type, user_id, uploaded_at)
     VALUES (?, ?, ?, ?, CURRENT_TIMESTAMP)`
  )
    .bind(
      object_key,
      head.size,
      head.httpMetadata?.contentType ?? 'application/octet-stream',
      metadata.user_id
    )
    .run();

  return Response.json({
    url: `https://cdn.example.com/${object_key}`,
    size: head.size,
  });
}
```

## Expo Client: XHR Upload with Progress

```typescript
// src/upload/uploadWithProgress.ts
import * as ImagePicker from 'expo-image-picker';
import * as FileSystem from 'expo-file-system';

export interface UploadProgress {
  loaded: number;
  total: number;
  percent: number;
}

export async function uploadImageWithProgress(
  asset: ImagePicker.ImagePickerAsset,
  onProgress: (p: UploadProgress) => void
): Promise<{ url: string; object_key: string }> {
  // 1. Get presigned URL from Workers
  const presignRes = await fetch('https://api.example.com/upload/presign', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${await getValidToken()}`,
    },
    body: JSON.stringify({
      filename: asset.fileName ?? 'photo.jpg',
      content_type: asset.mimeType ?? 'image/jpeg',
      size_bytes: asset.fileSize ?? 0,
    }),
  });

  const { upload_url, object_key } = await presignRes.json<{
    upload_url: string;
    object_key: string;
  }>();

  // 2. Read file as base64 → ArrayBuffer
  const base64 = await FileSystem.readAsStringAsync(asset.uri, {
    encoding: FileSystem.EncodingType.Base64,
  });
  const buffer = base64ToArrayBuffer(base64);

  // 3. PUT directly to R2 with XHR for progress events
  await new Promise<void>((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open('PUT', upload_url, true);
    xhr.setRequestHeader('Content-Type', asset.mimeType ?? 'image/jpeg');

    xhr.upload.onprogress = (event: ProgressEvent) => {
      if (event.lengthComputable) {
        onProgress({
          loaded: event.loaded,
          total: event.total,
          percent: Math.round((event.loaded / event.total) * 100),
        });
      }
    };

    xhr.onload = () => {
      if (xhr.status >= 200 && xhr.status < 300) resolve();
      else reject(new Error(`R2 PUT failed: ${xhr.status}`));
    };

    xhr.onerror = () => reject(new Error('Network error during R2 upload'));
    xhr.send(buffer);
  });

  // 4. Confirm with Workers
  const confirmRes = await fetch('https://api.example.com/upload/confirm', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${await getValidToken()}`,
    },
    body: JSON.stringify({ object_key, metadata: { user_id: getCurrentUserId() } }),
  });

  const { url } = await confirmRes.json<{ url: string }>();
  return { url, object_key };
}

function base64ToArrayBuffer(base64: string): ArrayBuffer {
  const binary = atob(base64);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) {
    bytes[i] = binary.charCodeAt(i);
  }
  return bytes.buffer;
}
```

## React Progress UI Component

```typescript
// src/components/UploadProgressBar.tsx
import React from 'react';
import { View, Text, StyleSheet } from 'react-native';
import { UploadProgress } from '../upload/uploadWithProgress';

interface Props {
  progress: UploadProgress | null;
}

export function UploadProgressBar({ progress }: Props) {
  if (!progress) return null;

  return (
    <View style={styles.container}>
      <View style={[styles.bar, { width: `${progress.percent}%` }]} />
      <Text style={styles.label}>
        {progress.percent}% ({formatBytes(progress.loaded)} / {formatBytes(progress.total)})
      </Text>
    </View>
  );
}

function formatBytes(bytes: number): string {
  if (bytes < 1024) return `${bytes} B`;
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`;
  return `${(bytes / (1024 * 1024)).toFixed(1)} MB`;
}

const styles = StyleSheet.create({
  container: { height: 20, backgroundColor: '#e0e0e0', borderRadius: 4, overflow: 'hidden' },
  bar: { height: '100%', backgroundColor: '#4caf50' },
  label: { position: 'absolute', alignSelf: 'center', fontSize: 11, color: '#333' },
});
```

## Retry on Transient R2 Failure

```typescript
// src/upload/retryUpload.ts
export async function uploadWithRetry(
  asset: ImagePicker.ImagePickerAsset,
  onProgress: (p: UploadProgress) => void,
  maxRetries = 3
): Promise<{ url: string; object_key: string }> {
  let attempt = 0;

  while (attempt < maxRetries) {
    try {
      return await uploadImageWithProgress(asset, onProgress);
    } catch (err) {
      attempt++;
      if (attempt >= maxRetries) throw err;

      // Exponential backoff: 1s, 2s, 4s
      await new Promise(r => setTimeout(r, 1000 * Math.pow(2, attempt - 1)));
    }
  }

  throw new Error('Upload failed after max retries');
}
```

## Anti-patterns

- **Using `expo-file-system` `uploadAsync` for presigned URLs** — it does not fire upload progress events for S3-style presigned PUTs; only `fetch`/XHR expose `ProgressEvent`.
- **Proxying large files through Workers** — Workers has a 100 MB body limit and adds latency; presigned direct-to-R2 is always preferable.
- **Not confirming after upload** — R2 accepts the PUT but if Workers never records it in D1, the object is orphaned and the CDN URL is never returned to the client.
- **Reading large files as base64** — `readAsStringAsync` with base64 loads the whole file into JS memory. For files > 20 MB, use `expo-file-system` streaming or chunked multipart (see `react-native-r2-multipart-upload-progress.md`).

---

## Gotchas

- **Hermes XHR and `ProgressEvent`** — Hermes on React Native supports XHR `progress` events since RN 0.72. On older RN versions, `event.total` may be 0 even when `Content-Length` is set; guard with `event.lengthComputable`.
- **R2 `Content-Type` must match presign** — the presigned URL includes the content type in the signature. If the client sends a different `Content-Type` header, R2 returns 403.
- **Clock drift on presigned URLs** — if the device clock is skewed by more than ±5 minutes, R2 rejects the presigned URL with `RequestTimeTooSkewed`. Workers should set `expiresIn` to 900 s to give plenty of margin.
- **`base64ToArrayBuffer` memory** — for 15 MB photos, base64 is ~20 MB string + 15 MB ArrayBuffer concurrently in Hermes. On low-RAM devices this can OOM. Test on 2 GB RAM devices.
