# Capacitor NativeAudio Workers Streaming Audio R2

Date: 2026-08-23
Author: example.com
Status: production

## Symptom / Use-case

An Ionic/Capacitor app needs to stream audio files (podcasts, music, guided meditations) stored in
Cloudflare R2. Attempts to use `<audio >` with R2 presigned URLs fail on iOS because
AVPlayer rejects unsigned or short-lived URLs mid-stream, and on Android because WebView audio
buffering stalls at the WebView/Native boundary. Teams want low-latency playback with progress
tracking synced back to a Cloudflare Workers + D1 backend.

## Context

`@capacitor-community/native-audio` bypasses WebView audio limitations by delegating to AVAudioPlayer
(iOS) and MediaPlayer/ExoPlayer (Android). Combined with R2 presigned URLs generated by a
Cloudflare Worker, this enables full-quality streaming without CORS complications or URL expiry
mid-stream (preload before playback; refresh before expiry).

Stack:
- Capacitor 6.x
- `@capacitor-community/native-audio` 7.x
- Cloudflare Workers (presign + progress sync endpoint)
- Cloudflare R2 (audio asset storage)
- Cloudflare D1 (playback progress persistence)
- TypeScript / Angular or React

## Cloudflare Worker: Presign + Progress Sync

```typescript
// worker/src/index.ts
import { Env } from './types';

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);

    if (url.pathname.startsWith('/audio/presign/') && request.method === 'GET') {
      return handlePresign(request, url, env);
    }

    if (url.pathname === '/audio/progress' && request.method === 'POST') {
      return handleProgress(request, env);
    }

    return new Response('Not found', { status: 404 });
  },
};

async function handlePresign(
  request: Request,
  url: URL,
  env: Env,
): Promise<Response> {
  const authHeader = request.headers.get('Authorization');
  if (!authHeader?.startsWith('Bearer ')) {
    return new Response(JSON.stringify({ error: 'Unauthorized' }), { status: 401 });
  }

  const key = url.pathname.replace('/audio/presign/', '');
  if (!key || key.includes('..')) {
    return new Response(JSON.stringify({ error: 'Invalid key' }), { status: 400 });
  }

  // Presigned URL valid for 30 minutes — long enough for a full audio file download
  const presignedUrl = await env.AUDIO_BUCKET.createPresignedUrl(key, {
    expiresIn: 1800,
  });

  return new Response(JSON.stringify({ url: presignedUrl, expiresIn: 1800 }), {
    headers: { 'Content-Type': 'application/json' },
  });
}

async function handleProgress(request: Request, env: Env): Promise<Response> {
  const { trackId, userId, positionSeconds } = await request.json<{
    trackId: string;
    userId: string;
    positionSeconds: number;
  }>();

  await env.DB.prepare(
    `INSERT INTO playback_progress (user_id, track_id, position_seconds, updated_at)
     VALUES (?, ?, ?, CURRENT_TIMESTAMP)
     ON CONFLICT (user_id, track_id) DO UPDATE
       SET position_seconds = excluded.position_seconds,
           updated_at = excluded.updated_at`,
  )
    .bind(userId, trackId, positionSeconds)
    .run();

  return new Response(JSON.stringify({ ok: true }), {
    headers: { 'Content-Type': 'application/json' },
  });
}
```

## Capacitor Audio Service

```typescript
// src/services/audioService.ts
import { NativeAudio } from '@capacitor-community/native-audio';

const WORKER_BASE = 'https://audio.example.workers.dev';
const PRESIGN_REFRESH_BUFFER_SEC = 120; // refresh URL 2 minutes before expiry

interface PresignResponse {
  url: string;
  expiresIn: number;
}

interface AudioTrack {
  id: string;
  r2Key: string;
  title: string;
  durationSeconds: number;
}

class AudioService {
  private loadedTrackId: string | null = null;
  private presignExpiry: number = 0;
  private progressInterval: ReturnType<typeof setInterval> | null = null;

  private async getPresignedUrl(r2Key: string, token: string): Promise<string> {
    const response = await fetch(
      `${WORKER_BASE}/audio/presign/${encodeURIComponent(r2Key)}`,
      { headers: { Authorization: `Bearer ${token}` } },
    );
    if (!response.ok) throw new Error(`Presign failed: ${response.status}`);
    const { url, expiresIn }: PresignResponse = await response.json();
    this.presignExpiry = Date.now() / 1000 + expiresIn - PRESIGN_REFRESH_BUFFER_SEC;
    return url;
  }

  async loadTrack(track: AudioTrack, token: string): Promise<void> {
    // Unload any previous track
    if (this.loadedTrackId) {
      await NativeAudio.unload({ assetId: this.loadedTrackId }).catch(() => {});
      this.loadedTrackId = null;
    }

    const presignedUrl = await this.getPresignedUrl(track.r2Key, token);

    await NativeAudio.preload({
      assetId: track.id,
      assetPath: presignedUrl,
      audioChannelNum: 1,
      isUrl: true,
    });

    this.loadedTrackId = track.id;
  }

  async play(
    trackId: string,
    startPositionSeconds: number,
    token: string,
    userId: string,
  ): Promise<void> {
    if (this.loadedTrackId !== trackId) {
      throw new Error(`Track ${trackId} not loaded. Call loadTrack() first.`);
    }

    await NativeAudio.play({ assetId: trackId, time: startPositionSeconds });

    // Sync progress every 10 seconds
    this.stopProgressSync();
    this.progressInterval = setInterval(async () => {
      try {
        const { currentTime } = await NativeAudio.getCurrentTime({ assetId: trackId });
        await this.syncProgress(trackId, userId, currentTime, token);
      } catch {
        // Non-fatal: progress sync failure should not interrupt playback
      }
    }, 10_000);
  }

  async pause(trackId: string): Promise<void> {
    await NativeAudio.pause({ assetId: trackId });
    this.stopProgressSync();
  }

  async seek(trackId: string, positionSeconds: number): Promise<void> {
    // NativeAudio 7.x supports seek via stop + play with time
    await NativeAudio.stop({ assetId: trackId });
    await NativeAudio.play({ assetId: trackId, time: positionSeconds });
  }

  private async syncProgress(
    trackId: string,
    userId: string,
    positionSeconds: number,
    token: string,
  ): Promise<void> {
    await fetch(`${WORKER_BASE}/audio/progress`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${token}`,
      },
      body: JSON.stringify({ trackId, userId, positionSeconds }),
    });
  }

  private stopProgressSync(): void {
    if (this.progressInterval !== null) {
      clearInterval(this.progressInterval);
      this.progressInterval = null;
    }
  }

  async dispose(): Promise<void> {
    this.stopProgressSync();
    if (this.loadedTrackId) {
      await NativeAudio.unload({ assetId: this.loadedTrackId }).catch(() => {});
      this.loadedTrackId = null;
    }
  }
}

export const audioService = new AudioService();
```

## iOS Background Audio Configuration

Add to `ios/App/App/Info.plist`:
```xml
<key>UIBackgroundModes</key>
<array>
  <string>audio</string>
</array>
```

In `ios/App/App/AppDelegate.swift`, activate the audio session for background playback:
```swift
import AVFoundation

@UIApplicationMain
class AppDelegate: UIResponder, UIApplicationDelegate {
    func application(
        _ application: UIApplication,
        didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
    ) -> Bool {
        do {
            try AVAudioSession.sharedInstance().setCategory(
                .playback,
                mode: .default,
                options: [.allowAirPlay, .allowBluetooth]
            )
            try AVAudioSession.sharedInstance().setActive(true)
        } catch {
            print("AVAudioSession setup failed: \(error)")
        }
        return true
    }
}
```

## Anti-patterns

- **Using `<audio>` in the WebView for R2 content** — iOS Safari's `<audio>` element cannot
  handle mid-stream URL rotation and stalls if the presigned URL expires during a long track.
- **Generating presigned URLs client-side** — R2 presigned URLs require the R2 secret key, which
  must never be embedded in the app binary. Always generate server-side via Workers.
- **Presign expiry shorter than track duration** — A 60-second expiry on a 90-minute podcast
  causes a mid-playback failure. Set expiry >= track duration + buffer.
- **Syncing progress on every `timeupdate` event** — This fires dozens of times per second. Batch
  to 10-second intervals and flush on pause/app background.
- **Not calling `NativeAudio.unload()` before switching tracks** — Leaks native audio resources
  and causes "asset already loaded" errors on re-preload.

## Gotchas

- `NativeAudio.preload()` with `isUrl: true` downloads the full file on iOS before playback
  begins. For large files, stream via AVQueuePlayer instead by implementing a custom Capacitor
  plugin.
- Android ExoPlayer (used under the hood) ignores `Content-Range` responses from R2 unless the
  Worker forwards the `Accept-Ranges: bytes` header. Add it explicitly in the presign response.
- Background audio on Android requires a foreground service. `@capacitor-community/native-audio`
  handles this automatically, but the notification channel must be configured before Android 8+.
- R2 presigned URLs are single-use if `x-amz-security-token` is present. Plain HMAC presigned
  URLs (no session token) are reusable within the expiry window.
