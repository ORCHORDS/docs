# ISO 23081-1:2017 Record Metadata Template Governance

## Purpose

ISO 23081-1:2017, "Information and documentation — Records management processes — Metadata for records — Part 1: Principles and methodology for metadata for records," defines principles for the metadata that supports records management. The standard provides a metadata framework that describes records (their content, context, and structure), and supports records control (capture, retention, disposition, access), and supports the integrity, authenticity, reliability, and usability of records over time. This article governs the application of ISO 23081-1 as a template for designing a record metadata schema and the policies for its use.

## Scope

The standard applies to any organization that creates and maintains records. Within this knowledge base, the article covers the principles (control, persistence, identification, context, integrity, authenticity, understandability, accessibility), the metadata categories (aboutness, agents, business context, recordkeeping system, rights, events, integrity, metadata about metadata), the metadata schema design, and the documentation of the metadata model. It does not cover a specific records management system implementation.

## Workflow

1. Apply the metadata principles the standard identifies: control, persistence, identification, context, integrity, authenticity, understandability, accessibility.
2. Identify the metadata requirements for each records management activity (capture, classification, retention, disposition, access). Each requirement maps to a metadata element.
3. Design the metadata schema: elements, definitions, data types, mandatory/optional status, sources, and value lists.
4. Apply the metadata at the points where records are captured (the metadata is most reliably captured at creation and use).
5. Maintain the metadata through the records management life cycle. Metadata must persist as long as the record itself.
6. Manage the integrity of metadata: protect against unauthorized change, and document any metadata changes that occur for valid reasons.
7. Document the metadata model and the policies for its use.

## Controls and evidence

Metadata controls include the metadata schema, the application policy (where metadata is captured, by whom, how), the validation (records complete with metadata), and the integrity controls. Evidence of disciplined metadata use includes sample records with complete metadata, audit trails of metadata changes, and retention records that demonstrate the metadata has persisted.

## Validation

Validation should confirm the metadata schema is documented, metadata is captured at the points defined by the policy, metadata persists with the record through the life cycle, integrity controls operate, and the schema is updated to reflect changes in records management. Sample checks across record categories confirm coverage.

## Failure correction

Common failure modes: metadata is captured at archival time rather than at record creation (corrective: capture at the point of record creation and reuse it); metadata is incomplete (corrective: define mandatory metadata and gate record capture on completeness); metadata changes are not audited (corrective: maintain an audit trail and restrict who can change metadata); metadata schema is uncontrolled and inconsistent across systems (corrective: adopt a single metadata model and integrate systems to it).

## Limitations

ISO 23081-1 is principles and methodology; it does not prescribe a specific metadata schema (Dublin Core, PREMIS, or sector-specific schemas). The standard assumes the organization has a records management policy and a system capable of capturing and maintaining metadata. The standard does not replace sector-specific records regulations.

## Scope note

This article summarizes project-neutral use of ISO 23081-1:2017 as a template. It does not assert any specific organization's records management conformance or claim any certification outcome.
