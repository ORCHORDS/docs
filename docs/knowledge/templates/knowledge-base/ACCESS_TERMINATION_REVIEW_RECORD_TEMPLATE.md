# Access Termination Review Record Template

## Purpose

Use this record to verify that access, credentials, authenticators, and organization-controlled assets are revoked or recovered when a person or third party no longer requires access.

- Review date:

- Systems in scope:

## Termination checks

- [ ] Interactive accounts disabled.
- [ ] API keys, tokens, certificates, and other authenticators revoked.
- [ ] Privileged roles and group memberships removed.
- [ ] Remote-access methods disabled.
- [ ] Physical credentials / devices / keys recovered where applicable.
- [ ] Shared secrets rotated where the subject had knowledge or access.
- [ ] Ownership of repositories, files, queues, dashboards, and service accounts transferred where needed.
- [ ] Retained business records remain accessible to authorized personnel.
- [ ] Exceptions are documented and time-bounded.
