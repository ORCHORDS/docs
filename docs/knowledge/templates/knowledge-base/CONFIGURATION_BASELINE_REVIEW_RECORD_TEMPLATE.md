## Current baseline
Record the approved configuration baseline, including relevant system components, security/privacy settings, connectivity, operational settings, and version identifiers.

## Review checks
- Confirm the baseline is current and formally approved.
- Compare deployed/configured state against the approved baseline.
- Identify unauthorized or unexplained deviations.
- Record changes caused by component installation or upgrades.
- Confirm evidence is sufficient to reproduce the review.
