# Template Round 5 Index

This round adds 50 reusable record templates covering NIST digital-identity and secure-software-development controls.

## Focus areas
- identity evidence validation and consistency
- identity proofing fraud, redress, exceptions, biometric and retention controls
- authenticator binding, replacement, recovery, loss and revocation
- federation audience, expiry, trust, privacy minimization and replay protection
- source repository and branch protection
- build environment, pipeline credentials, provenance and reproducibility
- signing, dependency trust, SBOM integrity, vulnerability validation
- secure review/testing, secret scanning, toolchain integrity and release traceability

Source basis: NIST SP 800-63A/B/C-4 and NIST SP 800-218 SSDF.
