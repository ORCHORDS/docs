# NIST CSF 2.0 GV.RM-05 Security Verification Profile

## Outcome

**GV.RM-05:** Lines of communication across the organization are established for cybersecurity risks, including risks from suppliers and other third parties

## Verification objective

Determine whether the defined scope has current, sufficient evidence for this outcome and identify where verification is incomplete.

## Verification steps

1. Identify the assets, identities, services, data, suppliers, or processes that make the outcome relevant.
2. Inspect the actual implementation, configuration, governance records, or operating evidence.
3. Test observable behavior where the outcome has a technical or operational surface.
4. Compare stated policy with evidence of execution.
5. Record gaps, exceptions, stale evidence, and dependencies on third parties.
6. Define the event or interval that triggers re-verification.

## Evidence classes

- implementation or configuration evidence;
- test or assessment evidence;
- operational records and monitoring where applicable;
- governance or decision records where applicable;
- supplier or external evidence when responsibility is shared.

## Assurance boundary

This profile is a verification aid. It is not evidence that the outcome is satisfied until the listed evidence has actually been reviewed for a defined scope.
