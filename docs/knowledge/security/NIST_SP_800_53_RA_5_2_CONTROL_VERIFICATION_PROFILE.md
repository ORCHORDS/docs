# NIST SP 800-53 RA-5.2 Update Vulnerabilities to Be Scanned Verification Profile

## Reference

- Control: **RA-5.2 — Update Vulnerabilities to Be Scanned**
- Family: Risk Assessment

## Verification objective

Determine whether the scoped implementation has sufficient current evidence for the selected control, including any organization-defined parameters and inherited responsibilities.

## Verification workflow

1. Confirm applicability and the governing profile or baseline.
2. Read the current NIST control text and assessment objectives.
3. Resolve organization-defined parameters before evaluating evidence.
4. Inspect design, configuration, implementation, and operating evidence as applicable.
5. Test relevant behaviors and failure cases where the control has a technical surface.
6. Record inherited or shared controls and verify the provider evidence relied upon.
7. Record gaps, exceptions, and re-verification triggers.

## Evidence classes

- architecture or implementation;
- configuration or policy;
- automated or manual assessment results;
- operational records;
- inherited-control evidence;
- exception and risk decisions.

This profile is not a compliance claim. Verification status depends on the actual scoped implementation and current evidence.
