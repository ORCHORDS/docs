# R2 Bucket Public Exposure Prevention and Audit

Date: 2026-08-23
Author: example.com
Status: production

---

## Symptom / Use-case

Your R2 buckets contain sensitive files—user uploads, internal reports, backup archives—and you need to verify that no bucket is accidentally exposed publicly, no object URL is guessable, and that presigned-URL access is scoped correctly. Teams routinely enable the R2 public dev URL (`r2.dev`) during development and forget to disable it before production, or they misconfigure a Worker to serve objects without authentication.

---

## Context

Cloudflare R2 has two public-access mechanisms that must be explicitly managed:

1. **`r2.dev` subdomain** (`pub-<hash>.r2.dev`): enabled per-bucket via the dashboard or API. When enabled, any object in the bucket is reachable by URL with no authentication.
2. **Custom domain** (via Workers or Pages): a Worker bound to an R2 bucket can serve objects publicly if the Worker does not enforce authentication.
3. **Presigned URLs**: generated by Workers using the `sign()` method; they expire but must be scoped tightly.

R2 has no object-level ACLs (unlike S3). Public exposure is an all-or-nothing configuration at the bucket level for `r2.dev`, and a code-level concern for Worker-served access. This makes auditing simpler: enumerate buckets, check their `public_development_url` flag, and audit every Worker that binds an R2 bucket.

## Auditing Bucket Public Access via the API

```typescript
// scripts/audit-r2-public-access.ts
// Run with: npx wrangler exec audit-r2-public-access.ts (or as a scheduled Worker)

interface R2BucketInfo {
  name: string;
  creation_date: string;
}

interface R2BucketDetail {
  name: string;
  public_development_url?: { enabled: boolean; domain: string };
}

async function auditR2Buckets(env: {
  CF_ACCOUNT_ID: string;
  CF_API_TOKEN: string;
}): Promise<void> {
  const listResp = await fetch(
    `https://api.cloudflare.com/client/v4/accounts/${env.CF_ACCOUNT_ID}/r2/buckets`,
    { headers: { Authorization: `Bearer ${env.CF_API_TOKEN}` } }
  );

  if (!listResp.ok) throw new Error(`List buckets failed: ${listResp.status}`);
  const { result } = await listResp.json<{ result: R2BucketInfo[] }>();

  const findings: string[] = [];

  for (const bucket of result) {
    const detailResp = await fetch(
      `https://api.cloudflare.com/client/v4/accounts/${env.CF_ACCOUNT_ID}/r2/buckets/${bucket.name}`,
      { headers: { Authorization: `Bearer ${env.CF_API_TOKEN}` } }
    );
    const { result: detail } = await detailResp.json<{ result: R2BucketDetail }>();

    if (detail.public_development_url?.enabled) {
      findings.push(
        `EXPOSED: bucket '${bucket.name}' has r2.dev public URL enabled: ${detail.public_development_url.domain}`
      );
    }
  }

  if (findings.length === 0) {
    console.log("PASS: No buckets have r2.dev public access enabled");
  } else {
    console.error("FAIL:\n" + findings.join("\n"));
    throw new Error(`${findings.length} bucket(s) publicly exposed`);
  }
}
```

## Disabling Public Access Programmatically

```typescript
// scripts/disable-r2-public-access.ts

async function disableR2DevURL(
  bucketName: string,
  accountId: string,
  apiToken: string
): Promise<void> {
  const resp = await fetch(
    `https://api.cloudflare.com/client/v4/accounts/${accountId}/r2/buckets/${bucketName}/domains/managed`,
    {
      method: "DELETE",
      headers: {
        Authorization: `Bearer ${apiToken}`,
        "Content-Type": "application/json",
      },
    }
  );

  if (resp.status === 404) {
    console.log(`Bucket '${bucketName}': r2.dev URL was not enabled (nothing to disable)`);
    return;
  }

  if (!resp.ok) {
    const body = await resp.text();
    throw new Error(`Failed to disable r2.dev for '${bucketName}': ${resp.status} ${body}`);
  }

  console.log(`Disabled r2.dev public URL for bucket '${bucketName}'`);
}
```

## Authenticated Worker Serving R2 Objects

When a custom domain serves R2 objects via a Worker, the Worker must enforce authentication before returning any object:

```typescript
// workers/src/r2-serve.ts
import type { Env } from "./types";

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    // 1. Authenticate the request (example: validate Bearer JWT)
    const authResult = await authenticate(request, env);
    if (!authResult.ok) {
      return new Response("Unauthorized", { status: 401 });
    }

    // 2. Authorise: verify the authenticated user may access this object
    const url = new URL(request.url);
    const objectKey = url.pathname.slice(1); // strip leading /
    if (!objectKey || objectKey.includes("..")) {
      return new Response("Invalid key", { status: 400 });
    }

    const tenantPrefix = authResult.tenantId + "/";
    if (!objectKey.startsWith(tenantPrefix)) {
      // Prevent cross-tenant object access
      return new Response("Forbidden", { status: 403 });
    }

    // 3. Fetch from R2 (never expose to unauthenticated callers)
    const object = await env.MY_BUCKET.get(objectKey);
    if (!object) {
      return new Response("Not Found", { status: 404 });
    }

    const headers = new Headers();
    object.writeHttpMetadata(headers);
    headers.set("Cache-Control", "private, max-age=300");
    // Prevent browser from inferring content type if metadata is wrong
    headers.set("X-Content-Type-Options", "nosniff");
    // Prevent embedding
    headers.set("Content-Disposition", `attachment; filename="${objectKey.split("/").pop()}"`);

    return new Response(object.body, { headers });
  },
};

async function authenticate(
  request: Request,
  env: Env
): Promise<{ ok: boolean; tenantId: string }> {
  const token = request.headers.get("Authorization")?.slice(7) ?? "";
  if (!token) return { ok: false, tenantId: "" };

  // Validate against your auth system (JWT, API key, etc.)
  // ...simplified example using a KV lookup:
  const tenantId = await env.AUTH_KV.get(`token:${token}`);
  if (!tenantId) return { ok: false, tenantId: "" };

  return { ok: true, tenantId };
}
```

## Presigned URL Scope Enforcement

Presigned URLs generated by Workers allow temporary unauthenticated access. Enforce tight expiry and URL signing:

```typescript
// workers/src/presign.ts
import type { Env } from "./types";

const MAX_EXPIRY_SECONDS = 3600; // 1 hour maximum

export async function createPresignedGetURL(
  bucket: R2Bucket,
  objectKey: string,
  expiresInSeconds: number
): Promise<string> {
  if (expiresInSeconds > MAX_EXPIRY_SECONDS) {
    throw new Error(`Presigned URL expiry ${expiresInSeconds}s exceeds maximum ${MAX_EXPIRY_SECONDS}s`);
  }

  // R2 presigned URL via Workers SDK
  const url = await bucket.createMultipartUpload(objectKey); // placeholder — see actual R2 sign API

  // Actual R2 presigned URL generation (requires the R2 bucket's public dev domain or custom domain):
  // Cloudflare R2 does not yet support presigned URLs via the Workers Binding API directly.
  // Use the AWS-compatible S3 endpoint with Cloudflare R2 credentials:
  return generateS3PresignedURL({
    accountId: "your-account-id",
    bucketName: "your-bucket",
    objectKey,
    expiresInSeconds,
    accessKeyId: "r2-access-key",
    secretAccessKey: "r2-secret-key",
    region: "auto",
  });
}

interface PresignOptions {
  accountId: string;
  bucketName: string;
  objectKey: string;
  expiresInSeconds: number;
  accessKeyId: string;
  secretAccessKey: string;
  region: string;
}

async function generateS3PresignedURL(opts: PresignOptions): Promise<string> {
  const endpoint = `https://${opts.accountId}.r2.cloudflarestorage.com`;
  const expires = Math.min(opts.expiresInSeconds, MAX_EXPIRY_SECONDS);
  const now = new Date();
  const dateStamp = now.toISOString().slice(0, 10).replace(/-/g, "");
  const amzDate = now.toISOString().replace(/[-:]/g, "").slice(0, 15) + "Z";
  const scope = `${dateStamp}/${opts.region}/s3/aws4_request`;

  const url = new URL(`/${opts.bucketName}/${opts.objectKey}`, endpoint);
  url.searchParams.set("X-Amz-Algorithm", "AWS4-HMAC-SHA256");
  url.searchParams.set("X-Amz-Credential", `${opts.accessKeyId}/${scope}`);
  url.searchParams.set("X-Amz-Date", amzDate);
  url.searchParams.set("X-Amz-Expires", String(expires));
  url.searchParams.set("X-Amz-SignedHeaders", "host");

  // Canonical request + signing (abbreviated; use a full SigV4 implementation in production)
  const signature = await computeSigV4(url, opts);
  url.searchParams.set("X-Amz-Signature", signature);

  return url.toString();
}

async function computeSigV4(url: URL, opts: PresignOptions): Promise<string> {
  // Full SigV4 implementation omitted for brevity.
  // Use @aws-sdk/signature-v4 or equivalent, bundled into the Worker.

}
```

## CI/CD Gate: Block Deployments with r2.dev Enabled

```typescript
// scripts/ci-r2-audit.ts — run in CI before deployment

async function ciR2AuditGate(): Promise<void> {
  const accountId = process.env.CF_ACCOUNT_ID!;
  const apiToken = process.env.CF_API_TOKEN!;
  const allowlist = (process.env.R2_PUBLIC_BUCKETS_ALLOWLIST ?? "").split(",").filter(Boolean);

  const resp = await fetch(
    `https://api.cloudflare.com/client/v4/accounts/${accountId}/r2/buckets`,
    { headers: { Authorization: `Bearer ${apiToken}` } }
  );
  const { result } = await resp.json<{ result: Array<{ name: string }> }>();

  const violations: string[] = [];

  for (const { name } of result) {
    const detailResp = await fetch(
      `https://api.cloudflare.com/client/v4/accounts/${accountId}/r2/buckets/${name}`,
      { headers: { Authorization: `Bearer ${apiToken}` } }
    );
    const { result: detail } = await detailResp.json<{
      result: { public_development_url?: { enabled: boolean } };
    }>();

    if (detail.public_development_url?.enabled && !allowlist.includes(name)) {
      violations.push(name);
    }
  }

  if (violations.length > 0) {
    console.error(`CI FAIL: These R2 buckets have public r2.dev URLs enabled: ${violations.join(", ")}`);
    process.exit(1);
  }

  console.log("CI PASS: No unauthorised R2 public buckets found");
}

ciR2AuditGate().catch(err => { console.error(err); process.exit(1); });
```

## Anti-patterns

- **Enabling `r2.dev` URL for development and forgetting to disable it**: Add a CI gate (see above) that fails the pipeline if any non-allowlisted bucket has `r2.dev` enabled.
- **Serving R2 objects from a Worker without authentication**: Any `env.BUCKET.get(key)` response returned without an auth check is a data leak waiting to happen.
- **Using sequential or guessable object keys** (e.g., `uploads/1.pdf`, `uploads/2.pdf`): Even if the `r2.dev` URL is disabled, internal endpoints may be brute-forced. Use `crypto.randomUUID()` or HMAC-derived key names.
- **Presigned URLs with long expiry**: Presigned URLs cannot be revoked; use the shortest practical expiry and log each generation.
- **Not restricting R2 API token permissions**: The token used for the S3-compatible presigned URL endpoint should have `Object Read` only on specific buckets, not `Account:Admin`.

---

## Gotchas

- **`r2.dev` is account-scoped, not per-bucket in legacy accounts**: Newer accounts require per-bucket opt-in; older accounts may have different defaults. Always audit programmatically rather than assuming.
- **Object metadata leaks bucket structure**: If you enable `r2.dev` on a bucket containing `tenant-a/private.pdf`, the full path including tenant prefix is exposed in the URL.
- **R2 does not support object-level ACLs**: You cannot make individual objects private within a publicly accessible bucket (unlike S3 with bucket-level public access blocks and object-level ACLs).
- **Workers cache can serve stale objects**: If you cache R2 responses in the Workers cache, verify that `Cache-Control: private` is set for authenticated content so the edge does not serve one user's content to another.
- **Terraform `cloudflare_r2_bucket`**: The Terraform provider may not expose the `public_development_url` field; verify with the API directly after `terraform apply`.

## Verification

```bash
# 1. List all buckets and check for public r2.dev domains
curl -s "https://api.cloudflare.com/client/v4/accounts/$CF_ACCOUNT_ID/r2/buckets" \
  -H "Authorization: Bearer $CF_API_TOKEN" | jq '.result[].name'

# 2. Check a specific bucket's public URL status
curl -s "https://api.cloudflare.com/client/v4/accounts/$CF_ACCOUNT_ID/r2/buckets/my-bucket" \
  -H "Authorization: Bearer $CF_API_TOKEN" | jq '.result.public_development_url'
# Expected for private bucket: null or {"enabled": false}

# 3. Attempt unauthenticated access to the Worker-served bucket endpoint
curl -si https://your-worker.example.com/uploads/some-file.pdf
# Expect: 401 Unauthorized

# 4. Run the CI audit script against production
CF_ACCOUNT_ID=$CF_ACCOUNT_ID CF_API_TOKEN=$CF_API_TOKEN \
  npx tsx scripts/ci-r2-audit.ts
```
