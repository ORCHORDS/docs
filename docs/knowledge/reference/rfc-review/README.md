# RFC Adoption Review Matrix — Batch 94

This directory provides one review record per RFC-series number in the Batch 94 coverage window. The records are intentionally lightweight evidence checkpoints rather than copies of RFC text. For each RFC, reviewers must use the RFC Editor as the canonical source and capture current publication status, update/obsolescence relationships, verified errata, security considerations, implementation compatibility, test evidence, and exceptions before relying on the RFC in production guidance.

## Canonical sources

- RFC Editor home and latest publications: https://www.rfc-editor.org/
- Per-RFC information pages: `https://www.rfc-editor.org/info/rfc<NUMBER>`
- RFC errata guidance: https://www.rfc-editor.org/series/rfc-errata/

Batch 94 exists to close the documentation-count target with source-grounded review records rather than copied RFC content or synthetic prose.
