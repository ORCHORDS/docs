# RFC adoption review record

Use the RFC number encoded in this file's name to open the canonical RFC Editor record at `https://www.rfc-editor.org/info/rfc<NUMBER>`. Before relying on that RFC, record its publication status, updates/obsoletes relationships, verified errata, security considerations, implementation compatibility, test evidence, and any approved exception. RFCs are immutable after publication; corrections are tracked through the RFC Editor errata system.

Source: RFC Editor — official home of the RFC Series.
