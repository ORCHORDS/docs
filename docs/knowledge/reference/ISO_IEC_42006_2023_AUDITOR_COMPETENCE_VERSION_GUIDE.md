## Scope

ISO/IEC 42006:2023 specifies competence requirements for auditors performing
third-party audits of AI management systems (AIMS) against ISO/IEC 42001:2023.
It is the accreditation baseline used by certification bodies seeking ISO/IEC
17021-1 recognition for AI system certification.

This guide captures the requirements structure, how it ties to ISO/IEC
42001:2023 audit clauses, and how ORCHORDS profiles the requirements when
operating or procuring AIMS audit services.

## Plan

When adopting ISO/IEC 42006:2023 as the auditor competence baseline, ORCHORDS
governs through the following steps:

1. Map the standard's competence dimensions to AIMS audit roles (lead auditor,
   technical expert, reviewer, certification decision maker).
2. Define minimum evidence of competence for each role: education, training,
   audit experience, technical knowledge, sector specialisation.
3. Capture ongoing professional development and surveillance calibration
   expectations for certified auditors.
4. Record third-party witness audit and calibration cadence so competence is
   not a point-in-time claim.
5. Publish the competence matrix to procurement so only accredited and
   competent audit teams are engaged for AIMS certification.

## Inputs

- Audit team CVs and qualification records.
- AIMS audit logs, working papers, and certification decisions.
- Witness audit reports from accreditation bodies.
- Calibration records across audit teams.
- Code of conduct and impartiality declarations.

## Implementation Notes

- Competence is maintained through a documented matrix rather than ad-hoc CV
  review. The matrix links each AIMS audit clause to the auditor role
  authorised to claim conformity.
- ORCHORDS treats third-party accreditation (ISO/IEC 17011) of the
  certification body as a precondition to accepting an AIMS certificate.
- Technical experts must demonstrate competence in the AI sector under audit
  (for example, machine learning model lifecycle, autonomous systems, or
  biometric AI) and not only generic management system auditing.
- Surveillance findings on auditor competence can invalidate certifications
  issued to ORCHORDS suppliers, which makes competence evidence a procurement
  artefact, not merely an HR document.
