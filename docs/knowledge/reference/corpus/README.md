# Engineering & Research Knowledge Base

**Independent software studio founded in 2025.**

This public knowledge base stores reusable engineering and research guidance. Content must remain neutral and portable: it must not identify or expose any specific product, repository, customer, deployment, issue tracker, internal project path, or confidential implementation.

## Public-repository boundary

Do not include project/product/repository names or URLs, branch names, issue/PR numbers, commit SHAs, deployment identifiers, tenant/account IDs, customer names, internal hostnames, local filesystem paths, organization-specific project paths, credentials, secrets, tokens, keys, cookies, `.env` values, private endpoints, customer/employee/banking/tax/transaction/legal records, confidential architecture, or unreleased implementation details.

Use generic placeholders only where an example needs an identifier.

## Research quality

- Search existing entries before adding a new concept.
- Prefer fresh primary and authoritative sources for current technical, standards, security, regulatory, or vendor claims.
- Preserve source dates/version context when it materially affects correctness.
- Do not convert recommendations into claims of implementation or compliance.
- Update stale guidance when authoritative sources change.
- Avoid near-duplicate pages.
