# Knowledge Base Overview

**Independent software studio founded in 2025.**

Maintain a reusable, project-neutral body of engineering and research knowledge that can be applied without exposing where a lesson originated.

## Neutrality requirement

Knowledge-base content must not name or identify specific products, projects, repositories, deployments, customers, issues, branches, commits, internal environments, local project directories, or private infrastructure.

Examples must use generic placeholders. Source citations may identify authoritative public standards, regulators, vendors, specifications, or research sources, but must not reveal private implementation context.

## Sensitive-data prohibition

Do not store credentials, secrets, authentication material, private endpoints, account identifiers, customer data, personal data, internal network details, banking/tax information, confidential transactions, or unreleased implementation details.
