# Synthetic Audio Deepfake Detection with Workers AI

Date: 2026-08-23 / Author: example.com / Status: production

---

## Symptom / Use-case

Voice messages, podcasts, and audio-embedded posts are increasingly generated by neural text-to-speech and voice-cloning systems. Bad actors use synthetic audio to impersonate public figures, spread false announcements, fake testimonials for financial scams, and generate harassment content while evading text-based classifiers. Standard perceptual-hash matching is ineffective against synthetic audio because each generated clip is unique.

## Context

example project processes audio uploads through a two-stage pipeline: a fast spectral-feature gate at upload time and a deeper neural detector for flagged clips. Detection results are stored in D1 alongside a provenance score. High-confidence synthetic clips are labelled in the UI; those matching known-voice cloning signatures are removed and queued for human review. The system is tuned for recall over precision — false negatives (missed fakes) are costlier than false positives in the current threat model.

Audio deepfakes fall into three categories on example project:
1. **Impersonation** — synthetic voice mimicking a named public figure.
2. **Anonymous synthetic** — TTS-generated voice, no specific target identity.
3. **Hybrid** — authentic recording with synthetic segments spliced in.

All three are detected; enforcement actions differ by category and confidence tier.

## Audio Ingestion and Preprocessing

```typescript
// workers/audio-ingest/preprocess.ts
import { Env } from '../../types';

export interface AudioMeta {
  r2Key: string;
  durationSeconds: number;
  sampleRate: number;
  channels: number;
  codec: string;
  sizeBytes: number;
}

/**
 * Audio objects are stored in R2 with custom metadata written by the
 * FFprobe-based ingest edge function. Workers AI accepts raw PCM
 * (16 kHz mono, 16-bit signed) or MP3/WAV up to 10 MB.
 */
export async function fetchAudioForClassification(
  r2Key: string,
  env: Env
): Promise<{ bytes: ArrayBuffer; meta: AudioMeta }> {
  const obj = await env.AUDIO_BUCKET.get(r2Key);
  if (!obj) throw new Error(`Audio object not found: ${r2Key}`);

  const meta: AudioMeta = {
    r2Key,
    durationSeconds: parseFloat(obj.customMetadata?.['x-duration'] ?? '0'),
    sampleRate: parseInt(obj.customMetadata?.['x-sample-rate'] ?? '0', 10),
    channels: parseInt(obj.customMetadata?.['x-channels'] ?? '1', 10),
    codec: obj.customMetadata?.['x-codec'] ?? 'unknown',
    sizeBytes: obj.size,
  };

  return { bytes: await obj.arrayBuffer(), meta };
}
```

## Spectral Gate — Fast First Pass

```typescript
// workers/audio-ingest/spectral-gate.ts

/**
 * A lightweight heuristic gate that runs entirely in the Worker runtime
 * without calling Workers AI. Synthetic TTS often exhibits:
 *   - Unusually uniform pitch variance (monotone prosody)
 *   - Absence of breath noise between sentences
 *   - Regular silence-to-voice ratio in clips under 60 s
 *
 * This is NOT a reliable detector; it is a routing filter.
 * Returns a suspicion score 0–1.
 */
export function spectralGateScore(meta: AudioMeta): number {
  let score = 0;

  // Flag very short clips with high sample rate (common TTS output profile)
  if (meta.durationSeconds < 5 && meta.sampleRate >= 44100) score += 0.2;

  // Clips > 30 min are almost certainly not synthetic (resource cost too high for attackers)
  if (meta.durationSeconds > 1800) return 0;

  // Unknown codec from upload pipeline suggests re-encoded TTS output
  if (meta.codec === 'unknown') score += 0.15;

  // Mono channel is slightly more common in TTS than authentic voice messages
  if (meta.channels === 1 && meta.durationSeconds > 30) score += 0.1;

  // Very precisely sized files are rare in organic recordings; TTS pipelines
  // often produce files in multiples of block size
  if (meta.sizeBytes % 4096 === 0) score += 0.05;

  return Math.min(score, 1);
}
```

## Workers AI Deepfake Classifier

```typescript
// workers/audio-ingest/ai-classify.ts
import { Env } from '../../types';

export type AudioVerdict =
  | 'authentic'
  | 'synthetic_anonymous'
  | 'synthetic_impersonation'
  | 'hybrid'
  | 'inconclusive';

export interface AudioClassification {
  verdict: AudioVerdict;
  confidence: number;
  processingMs: number;
}

/**
 * Routes to Workers AI audio classification.
 * The model returns a softmax over labels including 'real', 'fake', and
 * sub-labels for impersonation and hybrid segments.
 *
 * Audio is sent as a base64-encoded data payload because Workers AI
 * audio endpoints expect JSON, not multipart.
 */
export async function classifyAudio(
  audioBytes: ArrayBuffer,
  env: Env
): Promise<AudioClassification> {
  const t0 = Date.now();

  // Convert to base64 for JSON transport
  const b64 = btoa(
    String.fromCharCode(...new Uint8Array(audioBytes.slice(0, 5_000_000))) // first 5 MB
  );

  // Workers AI does not yet have a first-party deepfake audio model (2026-Q3);
  // route through AI Gateway to a hosted Resemblyzer / RawNet3-based endpoint.
  const response = await fetch(env.AUDIO_DEEPFAKE_MODEL_URL, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${env.AUDIO_MODEL_API_KEY}`,
      'Content-Type': 'application/json',
      'cf-aig-token': env.AI_GATEWAY_TOKEN,
    },
    body: JSON.stringify({ audio_b64: b64, max_duration_seconds: 120 }),
  });

  if (!response.ok) {
    throw new Error(`Audio model error: ${response.status}`);
  }

  const result = await response.json() as {
    label: string;
    confidence: number;
    sub_label?: string;
  };

  const verdict = mapLabel(result.label, result.sub_label);
  return { verdict, confidence: result.confidence, processingMs: Date.now() - t0 };
}

function mapLabel(label: string, subLabel?: string): AudioVerdict {
  if (label === 'real') return 'authentic';
  if (label === 'fake') {
    if (subLabel === 'impersonation') return 'synthetic_impersonation';
    if (subLabel === 'hybrid') return 'hybrid';
    return 'synthetic_anonymous';
  }
  return 'inconclusive';
}
```

## Persistence and Enforcement in D1

```typescript
// workers/audio-ingest/enforce.ts
import { Env } from '../../types';
import type { AudioVerdict } from './ai-classify';

export async function persistAndEnforce(
  audioId: string,
  r2Key: string,
  verdict: AudioVerdict,
  confidence: number,
  processingMs: number,
  env: Env
): Promise<void> {
  const now = Date.now();

  await env.DB.prepare(
    `INSERT OR REPLACE INTO audio_deepfake_verdicts
       (audio_id, r2_key, verdict, confidence, processing_ms, decided_at)
     VALUES (?, ?, ?, ?, ?, ?)`
  ).bind(audioId, r2Key, verdict, confidence, processingMs, now).run();

  if (verdict === 'synthetic_impersonation' && confidence >= 0.80) {
    // Remove immediately; queue for human review and possible CyberTip
    await env.AUDIO_BUCKET.put(r2Key, new Uint8Array(0), {
      customMetadata: { 'x-removed-reason': 'synthetic_impersonation', 'x-removed-at': String(now) },
    });
    await env.REVIEW_QUEUE.send({ audioId, r2Key, verdict, confidence, sla: now + 4 * 3_600_000 });
  } else if (verdict === 'synthetic_anonymous' && confidence >= 0.75) {
    // Label in UI; queue for soft review
    await env.DB.prepare(
      `UPDATE audio_posts SET synthetic_label = 1 WHERE audio_id = ?`
    ).bind(audioId).run();
    await env.REVIEW_QUEUE.send({ audioId, r2Key, verdict, confidence, sla: now + 24 * 3_600_000 });
  } else if (verdict === 'hybrid' && confidence >= 0.70) {
    // Apply reduced-reach flag; full review
    await env.DB.prepare(
      `UPDATE audio_posts SET reach_limited = 1 WHERE audio_id = ?`
    ).bind(audioId).run();
  }
  // 'authentic' and 'inconclusive' below threshold: no action; audit row already written
}
```

## D1 Schema

```sql
-- D1 migration: 0021_audio_deepfake.sql
CREATE TABLE IF NOT EXISTS audio_deepfake_verdicts (
  audio_id        TEXT PRIMARY KEY,
  r2_key          TEXT NOT NULL,
  verdict         TEXT NOT NULL CHECK(verdict IN
    ('authentic','synthetic_anonymous','synthetic_impersonation','hybrid','inconclusive')),
  confidence      REAL NOT NULL,
  processing_ms   INTEGER NOT NULL,
  decided_at      INTEGER NOT NULL,
  reviewed        INTEGER NOT NULL DEFAULT 0,
  reviewer_id     TEXT,
  reviewer_note   TEXT,
  final_verdict   TEXT
);

CREATE INDEX idx_adv_verdict   ON audio_deepfake_verdicts(verdict, confidence DESC);
CREATE INDEX idx_adv_reviewed  ON audio_deepfake_verdicts(reviewed, decided_at ASC);
```

## Anti-patterns

- **Running audio classification synchronously in the upload request.** Inference on a 3-minute clip can take 3–8 seconds; the request will timeout. Always offload to a Queue consumer.
- **Treating `inconclusive` as `authentic`.** Inconclusive clips should still enter a low-priority review queue rather than being silently approved.
- **Slicing only the first few seconds for classification.** Many hybrid deepfakes have an authentic opening segment to defeat short-clip detectors. Classify a 30-second window from the middle of long clips in addition to the opening.
- **Using the same confidence threshold for all verdict types.** Impersonation has higher stakes than anonymous synthetic; apply stricter action thresholds for impersonation and looser ones for labelling-only verdicts.

---

## Gotchas

- Workers AI Gateway imposes a 60-second request timeout. Audio clips longer than ~4 minutes at 16 kHz mono may exceed this; segment the audio and run the model on multiple windows, taking the max synthetic confidence across windows.
- Base64 encoding inflates payload size by ~33 %. A 5 MB audio clip becomes a ~6.7 MB JSON body; account for this in Workers memory limits (128 MB default) when processing many clips concurrently.
- Voice-cloning tools that use the target speaker's own recordings can produce embeddings nearly indistinguishable from authentic speech at the spectral level. The AI classifier provides probabilistic — not definitive — verdicts; human review remains necessary for enforcement above a certain confidence band.
- Cached AI Gateway responses will return stale predictions for the same audio bytes. Disable caching on the AI Gateway route for this model: `cf-aig-skip-cache: true` request header.
