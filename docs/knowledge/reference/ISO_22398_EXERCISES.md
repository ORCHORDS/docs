# ISO 22398 Exercises

## Scope

Reference card for ISO 22398:2013, *Societal security — Guidelines for exercises*. ISO 22398 provides the principles and general guidance for designing, conducting, and evaluating exercises for societal security, including business continuity, emergency management, and incident response. Profiles that govern an exercise programme should reference ISO 22398 and bind it to HSEEP, NIST SP 800-84, ISO/IEC 27035-3, and ISO 22301.

## Plan

1. Reference ISO 22398:2013 by version whenever a profile governs exercises for societal security.
2. Establish the exercise programme: scope, objectives, types (discussion-based, operations-based), frequency, and participants.
3. Exercise design: realistic scenarios, objectives, scope, success criteria, and evaluation framework.
4. Exercise conduct: controller, evaluator, simulator, player roles; safety controls; communications discipline.
5. Exercise evaluation: observer notes, participant feedback, success criteria scoring, deviation log, and findings.
6. Exercise improvement: corrective actions, updates to plans and procedures, updates to the training programme.
7. Bind to ISO 22301 for BCM context, to HSEEP for the methodology, and to NIST SP 800-84 for the IT-plan TT&E programme.

## Inputs

- ISO 22398:2013 normative sections.
- HSEEP methodology and after-action report template.
- Internal exercise programme: schedule, scenarios, participants, evaluation guides.
- Business continuity plan, incident response plan, and the related playbooks.

## ORCHORDS Profile

ORCHORDS treats ISO 22398:2013 as the canonical reference for societal-security exercises. Profiles that reference exercises should cite the standard by version, identify the exercise types in scope, and bind to HSEEP, NIST SP 800-84, and the relevant sector-specific standards.

A profile that references "exercises" without binding to a recognized methodology is non-conformant.

## Implementation Notes

- ISO 22398 is a guidelines document; the binding methodology in US jurisdictions is HSEEP.
- Exercise types map to different learning objectives; the type should match the objective.
- Safety controls during exercises are essential; production damage is a real risk.
- After-action reports and improvement plans are the primary evidence that the exercise programme is operating effectively.
- Improvement plans must be tracked to closure.
