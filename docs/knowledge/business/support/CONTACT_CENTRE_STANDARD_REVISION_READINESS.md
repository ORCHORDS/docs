# Contact Centre Standard Revision Readiness

## Purpose

ISO 18295-1:2017 remains the published international standard for customer contact centres, but ISO currently marks it to be revised. ISO/AWI 18295-1 is an Edition 2 project under development and has not yet replaced the 2017 edition.

## Practical use

Contact-centre owners should:

1. continue to treat ISO 18295-1:2017 as the published reference where it is used;
2. record that a replacement project exists and monitor its lifecycle;
3. avoid claiming conformity with requirements that appear only in unpublished drafts;
4. map current procedures, metrics, channel coverage, and service requirements so future changes can be assessed efficiently;
5. identify contracts or internal standards that hard-code an edition number; and
6. perform a controlled gap review only after a replacement edition is officially published.

## Sources

- ISO — ISO 18295-1:2017, Customer contact centres — Part 1: Requirements for customer contact centres: https://www.iso.org/standard/64739.html
- ISO — ISO/AWI 18295-1, Edition 2 under development: https://www.iso.org/standard/94393.html

## Scope note

An approved work item is not a published standard. This article intentionally separates revision monitoring from implementation requirements.
