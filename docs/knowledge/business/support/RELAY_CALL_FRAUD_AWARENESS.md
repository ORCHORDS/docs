# Relay Call Fraud Awareness

Accept legitimate relay-service calls while applying normal, nondiscriminatory fraud controls to the underlying transaction.

## Checks
- Do not reject a call merely because relay service is used.
- Verify transactions using controls appropriate to the action.
- Escalate suspicious behavior based on evidence, not communication method.

## Source
ADA Effective Communication: https://www.ada.gov/resources/effective-communication/
