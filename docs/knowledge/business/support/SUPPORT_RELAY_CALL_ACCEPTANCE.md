# Support Relay Call Acceptance

## Practice
- Train support agents to recognize telecommunications relay calls.
- Do not reject a support request solely because a relay operator is involved.
- Use ordinary identity controls without creating extra disability-based barriers.
- Document repeated routing or agent failures.
- Include relay calls in quality-assurance monitoring.

## Source basis
- U.S. Department of Justice ADA technical assistance: https://www.justice.gov/crt/americans-disabilities-act-technical-assistance-letters-3
