# Secure Remote Support Access

## Purpose

Remote-support tools can solve customer and operational problems quickly, but the same capabilities can expose systems and data if access is weak, persistent, or poorly controlled.

## Support-session controls

- Use approved remote-access software and known support channels.
- Authenticate the person requesting support before accessing sensitive systems or customer information.
- Grant only the minimum access needed for the task.
- Prefer time-bounded or session-specific access over permanent standing access.
- Require MFA for remote access to sensitive environments where supported.
- Keep endpoints patched and protected before they connect.
- Record the support owner, purpose, start/end time, and material actions when appropriate.
- End sessions promptly and remove temporary access after the task is complete.
- Review vendor contracts when third parties receive remote access to business systems.

## Abuse resistance

Remote-support staff should never ask customers or employees to bypass security controls merely for convenience. Unexpected requests for remote access should be independently verified through an official channel.
