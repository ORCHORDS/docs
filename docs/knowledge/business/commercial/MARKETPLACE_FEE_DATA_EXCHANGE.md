# Marketplace Fee Data Exchange

Define how marketplaces and sellers exchange fee data needed for accurate consumer-facing prices.

## Checks
- Assign ownership for each mandatory and optional charge.
- Validate data freshness and purpose labels.
- Reconcile seller data with displayed and final payment amounts.
