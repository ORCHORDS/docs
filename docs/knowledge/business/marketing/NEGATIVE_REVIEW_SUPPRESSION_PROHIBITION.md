# Negative Review Suppression Prohibition

Prevent review-management practices that selectively suppress legitimate negative feedback and create a misleading overall picture.

## Checks
- Apply moderation rules consistently.
- Document removal reasons.
- Prohibit threats or improper pressure to remove truthful negative reviews.
