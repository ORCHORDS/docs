# NAICS Industry Classification for Planning

## Purpose

The North American Industry Classification System (NAICS) provides a consistent way to identify the primary economic activity of a business. Selecting the appropriate NAICS code improves market-data comparisons because Census, SBA, contracting, and other public datasets frequently organize statistics or eligibility rules by industry.

## Practical use

1. Identify the activity that produces the business's primary product or service rather than choosing a code only because its label sounds familiar.
2. Use the current official NAICS search and definitions to compare nearby candidate codes.
3. Record the code and edition used in market research so later comparisons are reproducible.
4. Use the same classification when querying Census Business Builder, County Business Patterns, and related public datasets where appropriate.
5. Reassess classification when the business model materially changes or a newer NAICS edition changes the relevant industry structure.
6. Do not assume one NAICS code determines every legal, tax, licensing, or regulatory obligation; other systems may classify the business differently.

## Strategic value

A consistent industry code reduces false comparisons between businesses that operate in materially different markets. It also helps connect market-sizing work with SBA size standards and federal contracting analysis when those programs apply.

## Scope note

NAICS is an economic classification system. Selecting a code for analytical purposes does not by itself establish eligibility, licensing, taxation, or regulatory status.
