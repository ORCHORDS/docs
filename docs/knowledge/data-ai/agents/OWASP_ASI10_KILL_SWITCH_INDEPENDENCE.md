# Independent Agent Kill Switch

## Purpose

Control profile for **OWASP ASI10: Rogue Agents**.

## Control

Make emergency termination enforceable by infrastructure outside the model and orchestration path it is intended to stop.

## Validation

Simulate an unresponsive or adversarial agent and verify operators can terminate execution and revoke active authority externally.

## Failure correction

Stop the workload using the independent control, invalidate sessions, and repair any dependency on model cooperation.
