# Agent Escalation Policy

Define when an agent should stop autonomous work and surface the issue for review.

## Checklist
- Define escalation triggers for uncertainty, repeated failure, and missing authority.
- Include the evidence already gathered.
- Avoid looping after a terminal escalation condition.
- Record the resolution path for later evaluation.

## Primary sources
- OpenAI `openai/openai-agents-python` human-in-the-loop patterns.
- Cloudflare `cloudflare/agents` workflow patterns.
