# Anti-Dark-Pattern Agent Approval UI

## Purpose

Control profile for **OWASP ASI09: Human-Agent Trust Exploitation**.

## Control

Present approve, deny, modify, and defer choices neutrally; do not use model wording, urgency, or interface defaults to pressure a reviewer toward approval.

## Validation

Test time pressure, persuasive agent language, repeated prompts, and default selections; verify policy-critical choice remains explicit.

## Failure correction

Disable coercive presentation, review affected approvals, and update design checks for approval surfaces.
