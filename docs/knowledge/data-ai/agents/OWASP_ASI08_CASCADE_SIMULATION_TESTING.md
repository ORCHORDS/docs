# Cascading Failure Simulation Testing

## Purpose

Control profile for **OWASP ASI08: Cascading Failures**.

## Control

Exercise multi-agent systems with injected latency, denial, stale data, malformed messages, and partial service loss to verify containment before production incidents.

## Validation

Run controlled scenarios that cross agent, tool, and message boundaries and measure fan-out, retries, queue growth, and recovery.

## Failure correction

Turn each excessive propagation path into a tracked control improvement and retain the scenario as a regression test.
