# Agent Uncertainty Disclosure

## Purpose

Control profile for **OWASP ASI09: Human-Agent Trust Exploitation**.

## Control

Represent material uncertainty and evidence gaps to human reviewers instead of presenting uncertain model conclusions with false precision or certainty.

## Validation

Use tasks with known ambiguous evidence and verify the interface distinguishes uncertainty from a verified fact.

## Failure correction

Withdraw or annotate misleading output, correct confidence presentation, and add the scenario to evaluation data.
