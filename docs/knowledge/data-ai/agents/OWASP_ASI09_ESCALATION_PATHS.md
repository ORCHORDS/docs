# Human Escalation Paths

## Purpose

Control profile for **OWASP ASI09: Human-Agent Trust Exploitation**.

## Control

Give reviewers a clear route to escalate uncertain, conflicting, or suspicious agent actions instead of forcing binary approve-or-deny decisions.

## Validation

Present ambiguous policy and safety cases and verify the reviewer can defer to an appropriate authority without losing evidence.

## Failure correction

Pause the task, route it through the defined escalation path, and correct missing ownership or response targets.
