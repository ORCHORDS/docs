# Multi-Agent Supervisor

Use a supervisor when one component must coordinate several specialist agents.

## Checklist
- Keep supervisor responsibilities distinct from specialist execution.
- Bound delegation depth.
- Make completion criteria explicit.
- Trace delegated work and returned evidence.

## Primary sources
- OpenAI `openai/openai-agents-python` orchestration concepts.
- Cloudflare `cloudflare/agents` workflow patterns.
