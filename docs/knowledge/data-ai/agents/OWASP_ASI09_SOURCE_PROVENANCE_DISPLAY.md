# Source Provenance Display for Human Decisions

## Purpose

Control profile for **OWASP ASI09: Human-Agent Trust Exploitation**.

## Control

Expose the provenance and trust state of material sources that influenced a human approval, especially external or machine-generated evidence.

## Validation

Mix authoritative, user-supplied, generated, and unverified sources and verify the reviewer can distinguish them.

## Failure correction

Correct missing provenance in the decision view, invalidate affected approvals where material, and repair source lineage.
