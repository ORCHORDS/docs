# Agent User Intent Confirmation

Confirm user intent before ambiguous or consequential agent actions.

## Checklist
- Identify decisions that materially change external state.
- Summarize the intended action in user-understandable language.
- Preserve confirmed scope for the execution step.
- Reconfirm when important parameters change.
