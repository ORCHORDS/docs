# Agent Timeout Budgets

Assign time budgets to runs, tools, and nested work.

## Checklist
- Define total and per-step deadlines.
- Stop child work when the parent deadline expires.
- Preserve partial evidence for diagnosis.
- Return explicit timeout outcomes.
