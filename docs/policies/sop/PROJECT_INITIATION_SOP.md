# SOP: Project Initiation

## Procedure

1. Define problem/opportunity and intended outcomes.
2. Appoint sponsor and delivery owner.
3. Set scope, exclusions, key stakeholders, and delivery approach.
4. Record milestones, dependencies, assumptions, initial risks, and resources.
5. Identify required security, privacy, legal, operational, financial, accessibility, or compliance review.
6. Define acceptance and closure measures.
7. Approve, revise, defer, or reject initiation.
