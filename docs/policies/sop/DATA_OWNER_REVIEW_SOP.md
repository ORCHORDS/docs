# Data Owner Review SOP

1. Confirm the data set and accountable owner.
2. Review purpose, criticality, classification, access, quality, retention, sharing, and lineage.
3. Identify stale or missing records.
4. Assign actions by risk and due date.
5. Retain review evidence.
