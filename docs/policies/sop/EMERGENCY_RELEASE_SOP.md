# SOP: Emergency Release

## Trigger
Use when delay in normal release processing would materially increase security, availability, data-integrity, legal, or user-harm risk.

## Procedure
1. State emergency condition and accountable approver.
2. Restrict scope to necessary remediation.
3. Perform targeted review/testing sufficient for the immediate risk.
4. Confirm artifact integrity and release identity.
5. Define rollback/containment and monitoring.
6. Deploy through the safest available controlled path.
7. Verify expected remediation and health.
8. Record any ordinary controls compressed or skipped.
9. Conduct retrospective review and track remaining work.

## Completion
Emergency condition is mitigated and follow-up actions have owners.
