# Control Owner Attestation SOP

1. Confirm the assigned control and current owner.
2. Review design, operation, dependencies, evidence, and open exceptions.
3. Record gaps, uncertainty, or unavailable evidence.
4. Attest only to the supported period and scope.
5. Assign remediation actions and retain the record.
