# Milestone Recertification SOP

1. Review milestone purpose, owner, dependencies, evidence, and current sequence.
2. Test whether dates and acceptance expectations remain achievable and useful.
3. Rebaseline stale milestones when necessary.
4. Record the revised milestone state.
