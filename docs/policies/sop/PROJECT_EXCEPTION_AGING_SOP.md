# Project Exception Aging SOP

1. Review project exceptions by owner, age, scope, milestone impact, risk, and treatment.
2. Reassess assumptions and dependencies.
3. Escalate overdue or repeatedly deferred exceptions.
4. Record renewed acceptance, remediation, or closure.
