# Remediation Closure Verification SOP

1. Confirm remediation scope, owner, risk, and agreed completion criteria.
2. Review objective evidence that required actions were completed.
3. Test or otherwise verify effectiveness where appropriate.
4. Reopen incomplete work or record approved closure and residual risk.
