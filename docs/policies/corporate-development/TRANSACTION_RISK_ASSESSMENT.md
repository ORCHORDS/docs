# Transaction Risk Assessment

Material transactions require an integrated risk assessment covering strategic, financial, legal, regulatory, security, privacy, operational, supplier, customer, people, reputational, and integration risks.

Risks should have owners, evidence, treatment decisions, residual-risk views, dependencies, and explicit escalation for unresolved material issues.
