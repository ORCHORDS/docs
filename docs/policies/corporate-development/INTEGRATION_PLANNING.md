# Integration Planning

Integration planning should begin early enough to test transaction assumptions without violating confidentiality or pre-close legal boundaries.

Plans should cover governance, people, customers, suppliers, finance, legal/compliance, security/privacy, data, operations, technology, communications, records, milestones, risks, and decision rights.
