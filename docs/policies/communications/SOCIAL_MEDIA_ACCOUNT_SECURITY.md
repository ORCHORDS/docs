# Social Media Account Security

## Purpose

Protect official public communication accounts from takeover, impersonation, or unauthorized posting.

## Requirements

Official accounts SHOULD use named ownership, strong authentication, least-privilege access, secure recovery methods, periodic access review, and prompt removal of former contributors.

Shared passwords should be avoided where role-based or delegated access is available.

## Recovery

Maintain a documented recovery path that does not depend on one individual. Suspected takeover requires immediate containment, credential/recovery review, evidence preservation, and public correction if unauthorized content was posted.

See [Social Account Recovery SOP](../sop/SOCIAL_ACCOUNT_RECOVERY_SOP.md).
