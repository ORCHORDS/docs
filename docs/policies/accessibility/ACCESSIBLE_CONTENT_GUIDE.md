# Accessible Content Guide

## Purpose

Provide baseline accessibility rules for documentation and public content.

## Content rules

Authors SHOULD use logical heading order, descriptive links, plain language where precision allows, simple tables, meaningful alternative text, sufficient contextual labels, and captions or transcripts where needed.

Do not communicate critical meaning through color, position, or imagery alone.

## Documents

Avoid screenshots of text when actual text can be provided. Tables should not be used only for visual layout. Link text should make sense outside the surrounding sentence.

## Multimedia

Provide accessible alternatives appropriate to content type and user need, considering captions, transcripts, audio description, and control of motion or autoplay.

See [Accessibility Policy](ACCESSIBILITY_POLICY.md).
