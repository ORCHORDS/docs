# Emergency Access Governance

## Purpose

Permit time-critical privileged access without turning emergency procedures into a permanent bypass.

## Requirements

Emergency access SHOULD be limited to a defined incident or recovery need, use the minimum practical privilege and duration, create attributable records, require prompt post-use review, and trigger credential/session revocation or normalization after the emergency.

Where pre-approval is impractical, the action must be reviewed retrospectively by an accountable role independent of the operator where practical.

Emergency credentials, recovery codes, or access paths must not be documented in this public repository.

See [Emergency Access SOP](../sop/EMERGENCY_ACCESS_SOP.md).
