# Continuous Security Monitoring

## Purpose

Maintain ongoing awareness of security posture, threats, vulnerabilities, and control performance to support risk decisions.

## Program

Monitoring strategy SHOULD define important assets and controls, information sources, collection frequency, analysis ownership, escalation criteria, evidence retention, and response actions.

Continuous monitoring does not require every signal to be real-time. Frequency should follow risk and how quickly the condition can change.

## Quality

Measure signal usefulness, false positives, blind spots, stale checks, unowned alerts, and whether monitoring detects meaningful control failure.

## Privacy

Monitoring must minimize unnecessary personal data and follow authorized-purpose and retention requirements.
