# Security Telemetry Quality

## Purpose

Ensure security monitoring depends on meaningful, trustworthy, and maintainable signals.

## Requirements

Material telemetry SHOULD have an owner, defined security purpose, expected source, basic integrity and time assumptions, retention appropriate to need, and a review path for missing or noisy data.

Signal volume is not equivalent to coverage. Duplicate, unactionable, or chronically unreliable telemetry should be improved or retired.

Monitoring design must also respect privacy and data-minimization requirements.
