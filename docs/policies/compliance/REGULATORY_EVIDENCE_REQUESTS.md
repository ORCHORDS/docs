# Regulatory Evidence Request Governance

Formal evidence requests SHOULD be logged, scoped, assigned, reviewed for confidentiality and privilege, answered from authoritative sources, and tracked to completion. Responses must distinguish current evidence from planned remediation or unsupported claims.
