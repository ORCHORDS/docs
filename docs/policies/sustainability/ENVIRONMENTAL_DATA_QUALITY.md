# Environmental Data Quality

Environmental data should be assessed for completeness, accuracy, consistency, timeliness, lineage, estimation uncertainty, and suitability for the decision being made.

Material corrections must preserve an audit trail. Supplier-provided and modeled data should be distinguishable from directly measured internal data.
