# Sustainability Metrics and Measurement

Sustainability metrics require defined purpose, owner, formula, source data, boundary, frequency, quality checks, and interpretation guidance.

Metrics should distinguish leading indicators, activities, outputs, and outcomes. Method changes must be documented so trend comparisons are not misleading. Missing or estimated data should be visible in reporting.
