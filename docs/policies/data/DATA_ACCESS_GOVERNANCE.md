# Data Access Governance

## Purpose

Ensure access to governed data is justified, least-privilege, reviewable, and removed when no longer required.

## Requirements

Material access SHOULD identify purpose, data category, role or identity, approval basis, duration or review cadence, and any restrictions on export, sharing, or downstream use.

Sensitive-data access should be reviewed more frequently and require stronger authentication and logging where appropriate.

Bulk export, unusual cross-domain access, and privileged analytical access warrant additional review because their impact can exceed ordinary record-level access.

See [Data Access Review SOP](../sop/DATA_ACCESS_REVIEW_SOP.md).
