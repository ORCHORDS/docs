# Data Stewardship

## Purpose

Assign clear accountability for the meaning, quality, access expectations, lifecycle, and appropriate use of material data domains.

## Requirements

Material data domains SHOULD have an accountable steward or role responsible for definitions, quality expectations, access questions, retention coordination, issue escalation, and significant lifecycle changes.

Stewardship does not replace security, privacy, legal, or system ownership responsibilities; it coordinates data-specific accountability across them.
