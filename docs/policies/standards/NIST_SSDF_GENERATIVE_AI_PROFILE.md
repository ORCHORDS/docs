# NIST SSDF Generative AI Community Profile

## Purpose

Provide public governance guidance for applying NIST SP 800-218A to secure development of generative AI and dual-use foundation models.

## Baseline

NIST SP 800-218A is a final SSDF Community Profile published in July 2024. It augments, rather than replaces, the practices and tasks in SSDF Version 1.1 with AI-model-specific recommendations, considerations, notes, and references.

## Governance guidance

- use the profile together with the base SSDF rather than treating it as a standalone secure-development framework;
- identify security risks introduced by model training, evaluation, data handling, model artifacts, dependencies, and deployment interfaces;
- protect model-development assets and sensitive training or evaluation material proportionate to risk;
- incorporate adversarial testing and other model-specific verification where appropriate;
- track vulnerabilities and security-relevant model weaknesses through remediation and lessons learned;
- distinguish verified security evidence from broad claims that a model or AI system is “secure.”

## Verification

Confirm that AI-specific secure-development activities are mapped to relevant SSDF practices, supported by current evidence, and reviewed across the full model and software development life cycle.
