# Normative Language Convention

The corpus SHOULD use clear requirement language consistently. `MUST` expresses a mandatory requirement, `SHOULD` expresses a strong expectation with room for justified exception, and `MAY` expresses an allowed option. These terms do not automatically import requirements from an external standard.
