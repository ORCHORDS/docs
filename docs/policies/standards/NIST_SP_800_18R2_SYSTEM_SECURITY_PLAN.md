# NIST SP 800-18r2 System Security Plan

## Purpose

Summarize the system security plan element of NIST SP 800-18 Rev. 2.

## Guidance

A system security plan should provide a centralized description of the system, its authorization boundary, environments of operation, responsible roles, applicable security requirements, and the operational status of selected controls.

The plan should support risk-management decisions rather than function as a static inventory. Keep system purpose, components, interconnections, data flows, inherited controls, implemented controls, planned controls, and responsible parties current enough for authorization and ongoing risk management.

## Evidence

Useful evidence includes an approved plan, current boundary description, control implementation details, ownership assignments, architecture/data-flow references, review records, and documented changes affecting security posture.

## Verification

Confirm that plan content matches the actual system and that material architectural, control, ownership, or environment changes trigger review.

## Source

- NIST SP 800-18 Rev. 2, **Developing Security, Privacy, and Cybersecurity Supply Chain Risk Management Plans for Systems**, final June 30, 2026: https://csrc.nist.gov/pubs/sp/800/18/r2/final
