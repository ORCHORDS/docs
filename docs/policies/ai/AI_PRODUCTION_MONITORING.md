# AI Production Monitoring

## Purpose

Detect material degradation, misuse, safety failures, security events, or changed assumptions after AI-enabled capabilities enter use.

## Monitoring design

Depending on risk, monitoring SHOULD cover quality/failure trends, harmful or policy-relevant outputs, tool/action failures, unusual permission use, provider/model/configuration changes, user complaints, latency/availability, and indicators that evaluation assumptions no longer hold.

Monitoring must respect privacy and data-minimization requirements; collecting more user content is not automatically better assurance.

See [AI Monitoring Review SOP](../sop/AI_MONITORING_REVIEW_SOP.md).
