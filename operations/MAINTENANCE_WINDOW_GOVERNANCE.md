# Maintenance Window Governance

## Purpose

Plan service-affecting maintenance so user impact, recovery options, dependencies, and communications are considered before work begins.

## Requirements

Material maintenance SHOULD define scope, expected impact, owner, timing rationale, prerequisites, rollback or recovery approach, monitoring, and communication needs.

Recurring maintenance windows should not become a blanket exemption from normal change controls.
