# On-Call and Incident Duty

## Purpose

Define sustainable readiness for time-sensitive operational and security events.

## Expectations

Where on-call coverage is required, responsibilities SHOULD define covered scope, escalation path, handoff, access needed, runbooks, expected response behavior, and backup coverage.

## Sustainability

Schedules should avoid chronic overload, unclear ownership, or dependence on one person. Repeated pages from low-quality alerts indicate a monitoring problem rather than a need for greater tolerance from responders.

## Handoff

Active incidents and material unresolved risks require explicit handoff between duty periods.

See [On-Call Handoff SOP](../sop/ON_CALL_HANDOFF_SOP.md).
