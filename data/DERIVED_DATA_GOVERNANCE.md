# Derived Data Governance

## Purpose

Govern scores, aggregates, classifications, inferred attributes, and other data created from source information.

## Requirements

Material derived data SHOULD identify source categories, purpose, transformation logic at an appropriate level, owner, refresh behavior, known limitations, and whether the result changes sensitivity or access expectations.

Derived data should not be assumed harmless merely because it does not reproduce the original fields.
