# Remote Work Security

## Purpose

Set public-safe expectations for protecting company information and access outside controlled office environments.

## Requirements

Personnel SHOULD use approved devices and access methods, protect screens and conversations from unauthorized observation, secure devices against loss or theft, apply information-classification rules, and report suspected compromise promptly.

Sensitive work must not be performed on public or shared computers unless specifically authorized and protected.

## Physical environment

Consider family or visitor access, shared workspaces, travel, printed records, voice calls, and disposal of sensitive material.

## Connectivity

Remote network use must follow [Secure Remote Access](../security/SECURE_REMOTE_ACCESS.md). A familiar location does not make an untrusted network safe.
