# Contributing to ORCHORDS

Thank you for your interest in contributing! This project is maintained by
[ORCHORDS.COM](https://orchords.com).

## How to contribute

1. **Open an issue** first to discuss the change you want to make.
2. **Fork the repository** and create a branch from the default branch.
3. **Make your change** with clear, conventional commit messages
   (`feat:`, `fix:`, `docs:`, `chore:`, etc.).
4. **Open a pull request** referencing the issue it addresses.

## Code style

- Follow the existing conventions in the repository.
- Keep commits focused — one logical change per commit.

## Reporting security issues

Do **not** open a public issue for security vulnerabilities. See
[`SECURITY.md`](./SECURITY.md) or email `crm@orchords.com`.
