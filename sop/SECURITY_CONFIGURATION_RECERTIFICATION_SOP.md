# Security Configuration Recertification SOP

1. Review material baseline requirements and current applicability.
2. Identify drift, obsolete assumptions, unsupported settings, and exceptions.
3. Assign corrections or formal exception treatment.
4. Record recertification without exposing private configuration values.
