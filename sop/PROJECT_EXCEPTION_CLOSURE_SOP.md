# Project Exception Closure SOP

1. Review the project exception, owner, risk, scope, and accepted treatment.
2. Confirm remediation or changed conditions remove the need for the exception.
3. Verify milestone, quality, acceptance, and dependency impacts are addressed.
4. Record closure or renewed exception approval.
