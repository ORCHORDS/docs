# Security Drift Review SOP

1. Select material security controls or changed environments.
2. Compare approved expectations with current operation.
3. Record disabled safeguards, stale ownership, widened scope, or undocumented exceptions.
4. Rate resulting risk and assign remediation.
5. Verify closure through evidence.
