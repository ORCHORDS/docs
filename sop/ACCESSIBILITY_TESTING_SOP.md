# SOP: Accessibility Testing

## Trigger
Use for material public-interface changes, accessibility regression review, or scheduled verification.

## Procedure
1. Define scope, important journeys, and applicable accessibility criteria.
2. Run automated checks as an initial signal.
3. Perform keyboard-only review.
4. Check focus, semantics, zoom/reflow, contrast, forms/errors, and motion behavior as relevant.
5. Test important journeys with representative assistive technology where appropriate.
6. Record findings by user impact.
7. Fix or explicitly manage material barriers.
8. Retest and record closure evidence.
