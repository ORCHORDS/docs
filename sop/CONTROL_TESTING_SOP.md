# SOP: Control Testing

## Trigger
Use for scheduled assurance review, audit preparation, control changes, or repeated findings.

## Procedure
1. Define control objective, scope, period, and owner.
2. Evaluate control design.
3. Identify expected implementation evidence.
4. Select population/sample or automated test method appropriate to risk.
5. Perform test and retain traceable evidence.
6. Evaluate exceptions for impact and systemic pattern.
7. Conclude on design and operating effectiveness separately.
8. Assign remediation for material gaps.
9. Verify remediation before closure where practical.
