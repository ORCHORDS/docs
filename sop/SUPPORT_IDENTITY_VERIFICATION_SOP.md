# SOP: Support Identity Verification

## Trigger
Use before support performs a sensitive account action or discloses protected account information.

## Procedure
1. Classify requested action by sensitivity and takeover impact.
2. Use the strongest approved verification path appropriate to the action.
3. Prefer existing authenticated sessions or established recovery factors.
4. Never ask for passwords, recovery phrases, private keys, or reusable login secrets.
5. Check for suspicious context such as changed contact channels, urgency, or inconsistent account history.
6. If verification is insufficient, stop the sensitive action and escalate to the approved recovery path.
7. Record verification method category and decision without storing secrets.
