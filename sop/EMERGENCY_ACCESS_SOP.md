# SOP: Emergency Access

## Trigger

Use when an active incident or recovery need requires privileged action that cannot safely wait for the normal access path.

## Procedure

1. State the emergency purpose and affected capability.
2. Use the minimum practical privilege and duration.
3. Record the acting identity and authorization or, when pre-approval is impossible, the reason.
4. Preserve available audit evidence during the action.
5. Stop emergency use when the immediate need ends.
6. Revoke or normalize temporary privilege, sessions, and credentials.
7. Perform prompt independent post-use review where practical.
8. Escalate any unexpected access, control bypass, or security impact as an incident.
