# Sustainability Target Governance

Any public or internal sustainability target should define scope, baseline, target period, measurement method, accountable owner, dependencies, assumptions, and review cadence.

Targets must be distinguishable from forecasts and aspirations. Progress statements must disclose material boundary or methodology changes and must not imply achievement before evidence supports it.
