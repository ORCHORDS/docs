# Documented platform support is not runnable capacity

**Lesson:** A repository can describe macOS, Android, or browser validation without provisioning any executable target. Documentation establishes intent; only a dispatched, observed job establishes capacity.
**Date:** 2026-08-18
**Author:** ORCHORDS
**Status:** documented

## Operationalization

Inventory each promised target to workflow, runner label, owner, and smoke result. Mark absent capacity explicitly and prevent release claims from citing prose.

## Verification

Remove each runner label or credential and verify the matrix reports unavailable capacity rather than success.

## Gotchas

A setup guide, commented workflow, or locally reproducible command is not current CI evidence.
